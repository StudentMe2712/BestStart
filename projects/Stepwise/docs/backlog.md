# Stepwise — Backlog & Out-of-Scope Registry

> **Правило реестра:** Любая полезная идея или функция, обнаруженная во время разработки, но НЕ входящая в активную фазу, заносится сюда.  
> **Принцип:** *"Could be useful" ≠ "Must implement now"*. Самовольное добавление функций без утверждения оркестратором строго запрещено.

---

## Шаблон записи

```markdown
### [FEATURE-XXX] Название функции
- **Причина появления (Reason):** Почему возникла идея.
- **Потенциальная ценность (Potential value):** Что это даст пользователю или системе.
- **Сложность реализации (Complexity):** Low / Medium / High.
- **Зависимости (Dependencies):** Какие модули или фазы требуются.
```

---

## Отложенные функции (Deferred Features)

### [FEATURE-001] Пользовательские темы оформления (Custom Themes / Accent Colors)
- **Причина появления:** Возможность настраивать цвета UI помимо системных Dark/Light Windows.
- **Потенциальная ценность:** Персонализация под корпоративный стиль.
- **Сложность реализации:** Low.
- **Зависимости:** Фаза 3 (WinUI 3 Shell).

### [FEATURE-002] Встраиваемый видеоэкспорт шагов (MP4 / GIF Generator)
- **Причина появления:** Запрос на анимации между шагами.
- **Потенциальная ценность:** Наглядность для динамических действий (например, drag-and-drop).
- **Сложность реализации:** High.
- **Зависимости:** Фаза 6 (Экспорт), MediaComposition API.

### [FEATURE-003] Облачная синхронизация руководств (Cloud Sync / Team Sharing)
- **Причина появления:** Желание делиться руководствами между коллегами по ссылке.
- **Потенциальная ценность:** Коллаборация в командах.
- **Сложность реализации:** High (требует backend/auth).
- **Зависимости:** Пост-MVP, безопасность данных. Нарушает оффлайн-принцип ядра, поэтому строго изолировано в бэклог.

### [FEATURE-004] Плагин-система для сторонних AI провайдеров (Plugin Marketplace)
- **Причина появления:** Желание подключать любые LLM через DLL-плагины.
- **Потенциальная ценность:** Расширяемость экосистемы.
- **Сложность реализации:** High.
- **Зависимости:** Фаза 6 (AI). Достаточно стандартного интерфейса `IAIProvider`.

### [FEATURE-005] AI-генерируемые описания шагов (AI-Generated Descriptions)
- **Причина появления:** Формирование богатого контекстного описания шагов с помощью локальных/облачных LLM.
- **Потенциальная ценность:** Автоматическое составление документации без ручного ввода пользователем.
- **Сложность реализации:** Medium.
- **Зависимости:** Фаза 6 (AI Integration). Строго вынесено за рамки Stage 2 Core Recording.

### [FEATURE-006] Умная группировка действий (Smart Grouping)
- **Причина появления:** Слияние микро-действий пользователя (например, клик по полю, выделение текста, ввод, клик вне поля) в одну высокоуровневую логическую операцию.
- **Потенциальная ценность:** Уменьшение общего числа шагов в руководстве и повышение читаемости.
- **Сложность реализации:** High.
- **Зависимости:** Пост-Stage 2, эвристический анализ потока семантических действий.

### [FEATURE-007] Расширенное семантическое понимание UI (Advanced Semantic Understanding)
- **Причина появления:** Определение семантической роли элементов на основе OCR, компьютерного зрения и иерархических контекстных графов UI.
- **Потенциальная ценность:** Высокая точность идентификации нестандартных кастомных контролов (Canvas, Electron, DirectX).
- **Сложность реализации:** High.
- **Зависимости:** Компьютерное зрение, UIA v3 extension.

### [FEATURE-008] Автоматическое наименование сценариев (Automatic Naming)
- **Причина появления:** Автоматическая генерация названия руководства на основе первого активного процесса и последовательности ключевых действий.
- **Потенциальная ценность:** Экономия времени пользователя при сохранении гайда.
- **Сложность реализации:** Low / Medium.
- **Зависимости:** Фаза 6 (AI / Rule Engine).

### [FEATURE-009] Инференс рабочих процессов и намерений (Workflow & Intent Inference)
- **Причина появления:** Распознавание бизнес-процесса пользователя (например, "Оформление заказа", "Сброс пароля").
- **Потенциальная ценность:** Кластеризация руководств по бизнес-целям.
- **Сложность реализации:** High.
- **Зависимости:** Пост-MVP, аналитика графа переходов.

### [FEATURE-010] Воспроизведение и автоматизация сценариев (Guide Replay / RPA)
- **Причина появления:** Возможность автоматического повторения записанных шагов как RPA-робот.
- **Потенциальная ценность:** Автоматизация рутинных действий и регрессионное UI-тестирование.
- **Сложность реализации:** High.
- **Зависимости:** Фаза 7 (Guide Player / Automation Engine).
