### [x] #4 — True-multimodal ответ на вопрос про изображение · `P2` · `M` ✅
Сейчас изображение проходит pre-pass (vision → текст), и отвечает текстовая
модель по транскрипции.
- **Зачем:** выше точность по диаграммам/скриншотам/UI, когда вопрос именно про
  картинку.
- **Где:** `backend/app/llm.py` (путь, кладущий image_url-часть в основной
  стрим-вызов), `backend/app/routes/chat.py` (если есть изображения и включён
  флаг — маршрутизировать ответ через vision-модель), UI-тумблер.
- **Готово когда:**
  - [x] опциональный режим: картинка уходит прямо в отвечающую vision-модель,
        ответ стримится.
  - [x] деградация на текстовый pre-pass, если vision-модель недоступна.
- **Риски:** стриминг + персист с мультимодальным сообщением; квота/латентность.
  Оставить pre-pass дефолтом, multimodal — по тумблеру.
- **Сделано:** `llm.stream_vision()` + `vision_target()` (потоковый ответ
  Groq-vision/OpenRouter); `ChatIn.multimodal` + `Attachment.image_url` (data:-URL).
  В чате тумблер **«Vision»** появляется при прикреплённой картинке (дефолт OFF);
  картинка уходит частями image_url прямо в vision-модель, документы — текстом.
  Деградация: сбой vision ДО первого токена → текстовый pre-pass. Проверено
  живьём: красная картинка + ложная транскрипция «синее» → multimodal даёт
  «Красный» (vision-модель), обычный режим — «Синий» (текстовая). `pytest` 16,
  `tsc --noEmit` зелёные.
