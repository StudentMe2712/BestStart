## A. Доделать наполовину готовое (высокий ROI)

### [ ] #1 — Подключить контекст-чипы чата к ретриву · `P1` · `M`
Чипы `Использовать память / Материалы / Курсы / Избранное` сейчас — чистый
UI-стейт (в `page.tsx` прямой комментарий «на бэкенд пока не уходят»).
- **Зачем:** видимая фича выглядит рабочей, но ничего не делает — доверие/ценность.
- **Где:** `web/app/page.tsx` (стейт `useMemory/ctxMaterials/ctxCourses/ctxSaved` →
  в `streamChat`), `web/lib/api.ts` (тело запроса), `backend/app/routes/chat.py`
  (`ChatIn` + `_retrieve`/`_profile_facts` скоупинг).
- **Готово когда:**
  - [ ] `Использовать память` off → ретрив и профиль не подмешиваются в промпт.
  - [ ] `Материалы` off → `_retrieve_content` (content_chunks Лектора) исключается.
  - [ ] флаги доходят до бэка и реально меняют контекст (проверено).
- **Нюансы:** «Курсы» отдельно не индексируются (курс генерится из материала —
  своего эмбеддинга нет); «Избранное» (`saved_messages`) не эмбеддится. Для них —
  либо стретч (добавить эмбеддинг saved + признак «у источника есть курс»), либо
  на первом шаге сделать только `память`/`Материалы`, остальные пометить «скоро».

### [ ] #2 — «Запомнить файл»: вложение → ContentSource · `P1` · `M`
Распознанный текст вложения сейчас разовый (контекст одного ответа, в память не
кладётся).
- **Зачем:** объединяет вложения и Лектор — файл становится искомым и доступным
  для генерации курса.
- **Где:** `backend/app/routes/chat.py` или `learn.py` (новый POST, переиспользует
  `content.ingest_text`/`ingest_file` с уже распознанным текстом),
  `web/app/page.tsx` (кнопка «Запомнить» на `AttachChip`).
- **Готово когда:**
  - [ ] кнопка на чипе вложения создаёт `ContentSource` (chunked + embedded).
  - [ ] для изображений сохраняется vision-текст; для PDF — опц. и оригинал байт.
  - [ ] сохранённый файл виден в `/learn` и находится поиском/чатом.

## B. Новые фичи

### [ ] #4 — True-multimodal ответ на вопрос про изображение · `P2` · `M`
Сейчас изображение проходит pre-pass (vision → текст), и отвечает текстовая
модель по транскрипции.
- **Зачем:** выше точность по диаграммам/скриншотам/UI, когда вопрос именно про
  картинку.
- **Где:** `backend/app/llm.py` (путь, кладущий image_url-часть в основной
  стрим-вызов), `backend/app/routes/chat.py` (если есть изображения и включён
  флаг — маршрутизировать ответ через vision-модель), UI-тумблер.
- **Готово когда:**
  - [ ] опциональный режим: картинка уходит прямо в отвечающую vision-модель,
        ответ стримится.
  - [ ] деградация на текстовый pre-pass, если vision-модель недоступна.
- **Риски:** стриминг + персист с мультимодальным сообщением; квота/латентность.
  Оставить pre-pass дефолтом, multimodal — по тумблеру.

### [ ] #5 — Предпросмотр Word/Excel (не только текст) · `P2` · `L`
Сейчас настоящий предпросмотр только у PDF; docx/xlsx показываются как текст.
- **Зачем:** довести превью документов до уровня PDF.
- **Где:** хранить оригинал байт и для docx/xlsx (расширить логику `original_data`,
  что уже есть для PDF в `content.py`/`models.py`); рендер: `mammoth` (docx→html),
  SheetJS (xlsx→html) — на сервере в HTML или на клиенте; новый Hero в
  `web/app/courses/[id]/page.tsx`.
- **Готово когда:**
  - [ ] docx → читаемый HTML-предпросмотр; xlsx → таблица.
  - [ ] деградация на текст, если конвертация не удалась.

### [ ] #6 — Реформат больших документов в фоне с прогрессом · `P2` · `L`
Сейчас `reformat` кап 48k символов, хвост дописывается сырым, выполняется синхронно.
- **Зачем:** длинные материалы причёсываются целиком, без блокировки запроса.
- **Где:** `backend/app/formatting.py` (снять/повысить кап), фоновая задача
  (паттерн уже есть: `_schedule_learn`, `embed_pending_content`) + статус/прогресс,
  поле статуса у источника; `web/app/courses/[id]/page.tsx` (индикатор прогресса,
  поллинг).
- **Готово когда:**
  - [ ] реформат всего текста в фоне; UI показывает прогресс/готовность.
  - [ ] устойчивость к rate-limit (бэкофф уже частично есть — пауза между чанками).

### [ ] #7 — Экспорт курса в PDF/Markdown · `P2` · `M`
- **Зачем:** забрать курс наружу (поделиться, печать, оффлайн).
- **Где:** сборка markdown из `course.data` (модули→уроки→тест); MD — клиентский
  download; PDF — через print-stylesheet или серверную либу. Кнопка в
  `web/app/courses/[id]/page.tsx`.
- **Готово когда:**
  - [ ] экспорт в .md (содержание + уроки + тест).
  - [ ] экспорт в PDF (хотя бы через печать).
