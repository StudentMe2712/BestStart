## 1. Назначение и цели системы

**ИТС-Ком Wiki & Server Hub** — это специализированный корпоративный портал для системных администраторов, специалистов технической поддержки и инженеров 1С компании «ИТС-Ком».

### Ключевые бизнес-сценарии:
1. **Централизованный реестр инфраструктуры:** Ведение технических заметок по серверной инфраструктуре 25+ организаций-клиентов (параметры AnyDesk, mstsc/RDP, учетные записи Windows/доменов, СУБД MS SQL/PostgreSQL, параметры iLO/IPMI, дисковые массивы RAID).
2. **Учет конфигураций и релизов 1С:** Ведение реестра привязанных информационных баз с произвольным описанием релизов (например, `3.0.73.1 (БК), подсистема Строительство`), версий конфигураций и дат фиксации обновлений.
3. **Хронологический срез обновлений («События»):** Иерархический древовидный журнал баз 1С (по принципу регистра сведений 1С) для контроля актуальности релизов всех клиентов на одной странице.
4. **Быстрый безопасный доступ:** Копирование реквизитов строк в один клик, маскирование паролей, экспорт документации компании в PDF для печати и чистый TXT.

* **Backend:** Node.js (18+), Express 4.x.
* **Frontend:** EJS (Server-Side Rendering), Vanilla JavaScript (ES6+), CSS3 с CSS Custom Properties (дизайн-токены).
* **Шрифтовой стек:** `'JetBrains Mono', Consolas, 'SF Mono', Menlo, Monaco, monospace` для технических заметок и таблиц 1С; `'Segoe UI', system-ui, sans-serif` для интерфейсных элементов.

* **Тестирование:** Puppeteer Headless Chrome E2E тесты + нативные интеграционные скрипты Node.js.

## 3. Быстрый старт и локальная разработка

Система полностью автономна и не требует установленного MySQL на компьютере разработчика.

### 3.1. Запуск в 1 клик (Windows)
Просто запустите командный файл:
```cmd
projects\support\start-local.bat
```
Скрипт автоматически выставляет переменные окружения:
* `set DB_STUB=true`
* `set PORT=3000`
и запускает `node server.js`.

### 3.2. Ручной запуск через терминал
```bash
cd projects/support
npm install
npm run start:local
```

### 3.3. Учетные данные для входа по умолчанию:
* **URL:** `http://localhost:3000`
* **Логин:** `admin` (или `AdminITS`)
* **Пароль:** `admin` (или `admin123`)
* **Быстрое автозаполнение:** На экране `/login` есть кликабельный бейдж `Локальный доступ: admin / admin`, мгновенно заполняющий форму по клику.

## 5. Модели данных и СУБД

### 5.1. Пользователи (`users`)
| Поле | Тип | Описание |
|---|---|---|
| `id` | INT (PK, Auto-inc) | Уникальный ID сотрудника |
| `username` | VARCHAR(50) (UNIQUE) | Логин для входа (например, `admin`) |
| `password_hash` | VARCHAR(255) | Хэш пароля (Bcrypt, salt rounds 10) |
| `email` | VARCHAR(100) | Рабочий email |
| `created_at` | DATETIME | Дата регистрации |
| `last_login` | DATETIME | Дата последнего успешного входа |

### 5.2. Организации (`organizations`)
| Поле | Тип | Описание |
|---|---|---|
| `id` | INT (PK, Auto-inc) | Уникальный ID организации |
| `name` | VARCHAR(255) (UNIQUE) | Наименование клиента (например, `ALPHUTA`) |
| `content` | LONGTEXT | Свободные текстовые заметки по серверу |
| `created_at` | DATETIME | Дата создания карточки |
| `updated_at` | DATETIME | Дата последнего изменения заметок |

### 5.3. Информационные базы 1С (`organization_databases_1c`)
| Поле | Тип | Описание |
|---|---|---|
| `id` | INT (PK, Auto-inc) | Уникальный ID базы |
| `org_id` | INT (FK) | Ссылка на организацию (`organizations.id`) |
| `name` | VARCHAR(255) | Наименование базы (например: *Бухгалтерия (ЦБ)*) |
| `release_version` | TEXT | Произвольное текстовое описание (релиз, специфика) |
| `updated_at` | DATETIME | Дата последнего обновления базы |

> **Обратная совместимость:** В коде `db-stub.js` и `database.js` поле `release_version` двусторонне маппится как `description` и `release`.

## 6. Функциональные модули и страницы

### 6.1. Экран авторизации (`/login`)
* **Карточка 420px:** Центрированная карточка с мягким матовым стеклом `backdrop-filter: blur(16px)` и скруглением `16px`.
* **Минималистичный брендинг:** Чистый текстовый заголовок «ИТС-Ком» с подписью «База знаний» (полностью без графических картинок).
* **Контролы:** Поля ввода логина и пароля с иконками, интерактивная кнопка-глазок `#passwordToggleBtn` для скрытия/показа пароля, чекбокс «Оставаться в системе».
* **Переключатель темы:** Контурная SVG-кнопка (солнце/луна) с плавной сменой темы и сохранением в `localStorage`.
* **Безопасность учетных данных:** Бейдж быстрого локального входа `#quickCredsBadge` («Локальный доступ: admin / admin») изолирован условным рендерингом `<% if (isStubMode) %>`. На боевом хостинге Plesk (`DB_STUB=false`) блок полностью исключен из HTML-кода.

### 6.2. Главная страница / Дашборд (`/`)
* **Hero Bar:**
  * Приветствие: «С возвращением, **<%= user.username %>**» с подстановкой реального логина.
  * Заголовок: **«База знаний ИТС-Ком»**.
  * Динамическая системная дата на русском языке с заглавной буквы.
  * Индикатор телеметрии: «● Все узлы в штатном режиме».
* **Две сбалансированные карточки (строго по 1 предложению, без буллетов):**
  * **Карточка «Wiki»:** Бейдж `25 организаций`. Описание: *«Технические параметры серверов, доступы и конфигурации.»* → кнопка «Перейти в базу →».
  * **Карточка «События»:** Симметричный бейдж общего числа баз (`<%= totalDatabasesCount %> баз 1С`). Описание: *«Иерархический журнал и реестр информационных баз 1С.»* → кнопка «Перейти к событиям →».
* **Эргономика и центрирование:** Удален визуальный артефакт верхней синей полоски (`.command-hero::before`), карточки отцентрированы вертикально (`min-height: calc(100vh - 120px)`) с увеличенными отступами `padding: 36px 32px 32px`.

### 6.3. База знаний Wiki (`/wiki` и `/wiki/organization/:id`)
* **Левый сайдбар:** Живой мгновенный поиск по 25 серверам, счетчик серверов, подсветка активной компании, ресайзер ширины с сохранением в `localStorage`. Полное отсутствие лишних бейджей `PROD`/`DEV`.
* **Шапка карточки:** Двухбуквенный аватар-монограмма компании `44x44px` с фирменным синим градиентом (например, `AL` для ALPHUTA, `АП` для АстанаГенПлан) вместо безликого серого силуэта человека; заголовок организации, дата изменения и автор, кнопка «Редактировать», векторное меню «Ещё», навигация `‹` и `›`.
* **Два таба компании (`#companyTabsBar`):**
  1. **Таб «Данные»:** Контурная монохромная векторная SVG-иконка документа. Свободные заметки администратора (`.wiki-sheet`) с комфортной моноширинной типографикой (`JetBrains Mono`, 15px, line-height 1.6), подсветкой IP/паролей и кнопкой копирования отдельной строки. Программные номера строк кода удалены для чистого копирования текста мышью.
  2. **Таб «Базы 1С»:** Контурная векторная SVG-иконка базы данных со счетчиком баз. Таблица баз 1С (`Информационная база`, `Описание` — произвольный текст, `Дата`, `Действия`). Кнопка `+ Добавить базу` открывает модалку с обычным `<input type="text">` для описания. Все поля формы снабжены `autocomplete="off"`, кнопка «Сохранить» оформлена в основном синем цвете (`--brand-primary`). Поддерживается полный AJAX CRUD без перезагрузки страницы.
* **Режим редактирования:** Переход в WYSIWYG-редактор чистого текста с кнопками «Сохранить» и «Отмена» и автосохранением черновика.

### 6.4. Журнал релизов 1С — «События» (`/events`)
* **Строгое 1С-дерево (дерево значений):**
  * По умолчанию все компании **строго свернуты**.
  * Квадратный переключатель `[+]` (раскрывается в `[-]`).
  * Клик по строке компании раскрывает список её баз.
  * Ссылка перехода в карточку Wiki `↗` снабжена поясняющим тултипом `title="Перейти в карточку компании в Wiki"`.
* **Фильтрация пустых строк:**
  * Интерактивный тумблер `[x] Только с базами 1С` активен по умолчанию и скрывает организации без привязанных баз, избавляя от рутинного скроллинга.
  * Состояние переключателя персистентно сохраняется в `localStorage`.
* **Ограничение ширины:** Контейнер таблицы ограничен `max-width: 1400px; margin: 0 auto;`, исключая разрыв колонок на мониторах 2K и 4K.

### 6.5. Профиль пользователя (`/profile`)
* Просмотр учетных данных, даты регистрации, даты последнего входа и обновление рабочего email.

## 7. Подсистема экспорта (PDF и TXT)

Для гарантированной надежности система не зависит от процессов Puppeteer/Chromium на сервере.

### 7.1. Экспорт в PDF (`GET /api/export/pdf/:id`)
* Сервер отдает специально подготовленный Printable HTML View:
  * Чистая печатная разметка с `@media print` (поля 15 мм, оптимизация под формат А4).
  * Включает реквизиты компании, метаданные, полные текстовые заметки и таблицу баз 1С с описанием.
  * Встроенный скрипт автоматического вызова печати:
    ```javascript
    window.addEventListener('DOMContentLoaded', () => {
        setTimeout(() => window.print(), 400);
    });
    ```
  * Вверху страницы выводится бар с кнопками «🖨 Напечатать / Сохранить как PDF» и «← Вернуться в Wiki» (скрываемый при печати).
  * Пользователь штатно сохраняет документ в PDF средствами браузера без риска падения Node.js.

### 7.2. Экспорт в TXT (`GET /api/export/txt/:id`)
* Отдает чистый файл с заголовками:
  * `Content-Type: text/plain; charset=utf-8`
  * `Content-Disposition: attachment; filename="<org_name>.txt"`
* Файл содержит полный текст заметок, а также структурированный реестр привязанных баз 1С.

## 8. Дизайн-система, темы и типографика

### 8.1. Дизайн-токены (CSS Custom Properties)
В `public/css/style.css` определена система токенов:
* Цвета поверхностей: `--bg-primary`, `--bg-surface`, `--bg-surface-translucent`, `--bg-card`.
* Текст: `--text-primary`, `--text-secondary`, `--text-muted`, `--text-subtle`.
* Границы и тени: `--border-color`, `--border-color-subtle`, `--shadow-card`, `--shadow-md`.
* Акценты: `--brand-primary` (`#3b82f6`), `--brand-accent`, `--color-success` (`#22c55e`), `--color-danger` (`#ef4444`).

### 8.2. Темная и светлая темы
* Переключение темы через кнопку с иконками солнца/луны `#themeToggle`.
* Тема устанавливается атрибутом `data-theme="dark"` на корневом теге `<html>`.
* Состояние темы сохраняется в `localStorage` с привязкой к логину пользователя (`ui_theme_<username>`).

### 8.3. Типографика
* Подключен моноширинный шрифт **JetBrains Mono** (400, 500, 600, 700).
* Высота строки для заметок: `line-height: 1.6`.
* Размер шрифта в карточке: `15px`.

### 8.4. Векторные SVG-иконки в меню «Ещё»
* Все растровые картинки и эмодзи заменены на чистые контурные векторные SVG-иконки (PDF, TXT, Корзина).
* Функция интернационализации `i18n.js` защищает вложенные SVG от стирания при переключении языков.

## 9. Справочник REST API

Все маршруты API защищены авторизацией `requireAuth` (возврат HTTP 401 или редирект на `/login`).

### Аутентификация и сессия
| Метод | URL | Описание |
|---|---|---|

## 12. Архитектурные решения (ADR 001–006) и история спринтов

* **ADR-001: Локальный In-Memory Mock (`db-stub.js`):**
  * *Проблема:* Отсутствие локального MariaDB сервера приводило к сбою старта Express.
  * *Решение:* Создан `db-stub.js` с 25 предзаполненными организациями, пользователями `admin/admin` и таблицами баз 1С. Включается через `DB_STUB=true`.
* **ADR-002: Свободный моноширинный текст вместо жестких таблиц формы:**
  * *Проблема:* Разделение заметок на фиксированные поля («Удаленный доступ», «СУБД») привело к появлению статусов «Не указано» и сломало естественный текст сисадминов.
  * *Решение:* Заметки отображаются как моноширинный лист (`JetBrains Mono`, 15px, line-height 1.6) и подсветкой параметров.
* **ADR-003: Двухсекционная карточка компании (Табы «Данные» и «Базы 1С»):**
  * *Решение:* Контент разделен на две понятные вкладки: системные заметки и реестр конфигураций 1С. Поле описания базы является свободным текстовым `input`.
* **ADR-004: Иерархическое дерево в «Событиях» (Стиль 1С:Предприятие):**
  * *Решение:* Организации свернуты по умолчанию. Раскрытие выполняется через аккуратный квадратный плюсик `[+]` ⇄ `[-]`. Организации с 0 баз отображаются компактно без плюсика. Верхний хаос (кнопки, поиск) удален.
* **ADR-005: Отказ от бинарников Chromium в пользу Printable View:**
  * *Проблема:* Сбои процесса Puppeteer вызывали ошибку `{"error":"Ошибка экспорта в PDF"}`.
  * *Решение:* Маршрут `/api/export/pdf/:id` генерирует легкий HTML-шаблон с `@media print` и автовызовом `window.print()`, сохраняемый через штатный диалог браузера.
* **ADR-006: Эргономика, безопасность dev-подсказок, фильтрация пустых баз и монограммы:**
  * *Проблема 1 (Безопасность):* Бейдж локального доступа `admin / admin` рендерился в HTML на боевом сервере Plesk.
  * *Решение 1:* Внедрен условный EJS-рендеринг `<% if (isStubMode) %>`, полностью исключающий блок из DOM в продакшене.
  * *Проблема 2 (UX / Автокомплит):* Браузерное меню автозаполнения перекрывало модальное окно добавления базы 1С; кнопка сохранения имела выбивающийся зеленый цвет.
  * *Решение 2:* Атрибут `autocomplete="off"` добавлен на форму и поля, кнопка унифицирована в цвет дизайн-системы `--brand-primary`.
  * *Проблема 3 (Информационная перегрузка):* В «Событиях» 22 из 25 компаний без баз создавали визуальный шум; на экранах 2K/4K строки растягивались без ограничений.
  * *Решение 3:* Внедрен дефолтный тумблер `[x] Только с базами 1С` с сохранением в `localStorage` и ограничение контейнера `max-width: 1400px; margin: 0 auto;`.
  * *Проблема 4 (Визуальная эстетика):* В Wiki серый силуэт человека не отражал корпоративную идентичность компании; в режиме чтения номера строк мешали выделению текста; в табах использовались разношерстные цветные эмодзи.
  * *Решение 4:* Внедрена функция динамической генерации двухбуквенной монограммы `getOrgMonogram()` с градиентным аватаром `44x44px`, табы переведены на монохромные SVG, номера строк `.wiki-line-num` исключены из DOM.
