# 📘 Спецификация проекта: ИТС-Ком Wiki & Server Hub (BestStart)

**Версия:** 2.7.0  
**Статус:** Завершен (Спринт 7 — Full-Width Hero Dashboard, Per-User Pinned Orgs, File Attachments with Lightbox, Password Reset & Security Hardening)  
**Локация:** `projects/support`  
**Стек:** Node.js 18+, Express 4.x, EJS, Vanilla CSS/JS, MariaDB (Прод Plesk) / Mock Stub (Dev)  
**Корпоративный навык:** `its-support`

---

## 1. Контекст архитектуры и стек проекта

- **Backend:** Node.js 18+, Express 4.x, EJS-шаблоны, Vanilla JavaScript (ES6+).
- **Стилизация:** CSS3 Custom Properties (дизайн-токены), адаптивная верстка (Flexbox/Grid), поддержка темной и светлой тем (`data-theme="dark"` / `light`).
- **База данных (Dual-Engine):**
  - **Production (Plesk):** MariaDB/MySQL (`p-14802_wiki`) через пул `mysql2/promise` с параметризованными запросами (`?`).
  - **Development (Local):** In-memory мок `db-stub.js` при `DB_STUB=true` (логин: `admin` / `admin`).
- **Хранилище файлов:** Защищенная изолированная папка `uploads/org_<id>/` вне публичной статики `public/` с проверкой прав доступа сессии.

## 2. Регламент компонентов и UI-стандарты (Спринты 1–6)

### 2.1. Экран авторизации (`/login`)
* **Безопасность учетных данных:** Блок подсказки «Локальный доступ: admin / admin» отображается исключительно в локальном dev-окружении (`isStubMode === true`). На боевом хостинге Plesk подсказка скрыта.
* **Переключатель темы:** Контурная векторная SVG-кнопка (солнце/луна) с поддержкой темной и светлой темы.
* **Закрытый контур:** Публичная регистрация отключена.

### 2.2. Карточка организации в Wiki (`/wiki`)
* **Аватар организации:** Автоматическая генерация монограммы из двух заглавных букв наименования компании (например, `АП` для Автоперекрестка, `AL` для ALPHUTA) в аккуратном блоке `44x44px` с фирменным сапфировым фоном.
* **Чистый лист заметок:** Моноширинный блок (`JetBrains Mono`, 15px) без программных номеров строк для комфортного выделения, чтения и копирования параметров доступов.
* **Экспорт:** Встроенный экспорт технической карточки компании в PDF (через системный диалог печати) и чистый TXT.
* **Консервация баз 1С:** Табы баз 1С и модальное окно баз временно законсервированы в коде для фокусировки на чистом серверном Wiki.

### 2.3. Журнал «События» (`/events`)
* **Консервация раздела:** Раздел «События» законсервирован (ссылки скрыты из навигации, роуты возвращают 404).

### 2.4. Главная страница (Дашборд `/`)
* **Широкий экранный контейнер:** Ограничение рабочей области `max-width: 1320px; width: 100%; margin: 0 auto;`.
* **Симметрия и баланс:** Верхний баннер приветствия и Hero-карточка базы знаний строго выровнены по ширине.

## 3. Архитектурные решения (ADR)

### ADR-001 — ADR-005: Базовая архитектура, Dual-Engine DB, монограммы и чистый текстовый лист
* **Dual-Engine:** Бесшовное переключение между MariaDB на Plesk и in-memory моком `db-stub.js` без сторонних СУБД в локальной среде разработки.
* **Стилистическое единство:** Использование дизайн-токенов CSS3 переменными, отказ от эмодзи в интерфейсных контролах в пользу чистых векторных SVG-иконок.
* **Монограммы:** Алгоритмическая генерация монограмм компаний для надежного визуального распознавания без загрузки внешних логотипов.

### ADR-006: Закрытая регистрация, двухшаговый сброс пароля и Rate Limiting (без блокировки по IP)
* **Статус:** Принято / Реализовано (Спринт 7)
* **Контекст:** Портал ИТС-Ком является закрытой корпоративной базой знаний. Открытая публичная регистрация несет риски несанкционированного доступа. Требуется защитить вход и предоставить сотрудникам легитимный механизм сброса забытого пароля без жестких IP-банов.
* **Решение:**
  1. **Закрытие регистрации:** Полное отключение маршрутов `GET /register` и `POST /register`, удаление ссылок на регистрацию из шапки и формы входа.
  2. **Двухшаговый сброс пароля на `/login`:** 
     - Шаг 1: Верификация логина (`POST /api/auth/verify-login`).
     - Шаг 2: Ввод нового пароля с подтверждением и кнопкой-глазком (`POST /api/auth/reset-password`, мин. 8 символов, bcrypt-хеширование).
  3. **In-memory Rate Limiter (без IP-блокировок):** Ограничение до 5 неудачных попыток за 15 минут с одного IP на эндпоинты аутентификации (HTTP 429). После успешного действия счетчик очищается.
  4. **Security Hardening:** Заголовки `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: same-origin`, куки `httpOnly: true`, параметризованные SQL-запросы (`?`).

### ADR-007: Масштабный Hero-дашборд (1320px), персональные Pin-закладки и файловые вложения с лайтбоксом
* **Статус:** Принято / Реализовано (Спринт 7)
* **Контекст:** Администраторам и инженерам поддержки требуется моментальный доступ к часто используемым организациям, возможность прикреплять схемы сетей, таблицы портов Excel, PDF-регламенты прямо в карточку Wiki с быстрым предпросмотром, а также современный презентабельный вид главной страницы во всю ширину экрана.
* **Решение:**
  1. **Масштабная Hero-карточка «Wiki» на Главной:**
     - Расширение дашборда до `max-width: 1320px; width: 100%; margin: 0 auto;`.
     - Двухколоночный Hero-блок (`min-height: 400px`, `padding: 44px 48px`, сетка `1.25fr 1fr`):
       - Слева: крупный заголовок `Wiki — Серверная база знаний` (30px), подробное описание, плашки-теги (`25 организаций`, `Вложения Excel / PDF / Схемы`, `Экспорт PDF и TXT`), крупная кнопка «Перейти в базу знаний →».
       - Справа: векторная SVG-иллюстрация серверной инфраструктуры в корпоративных синих тонах + интерактивный блок «Мои закрепленные организации 📌».
  2. **Персональное закрепление компаний (Pin 📌):**
     - Хранение в таблице `user_pins` (`user_id`, `org_id`) и in-memory моке. Закрепления индивидуальны для каждого пользователя (`admin`, `AdminITS` и др.).
     - SVG-кнопка булавки у каждой компании в сайдбаре Wiki. При клике компания закрепляется и поднимается в верхнюю подгруппу «Закрепленные».
  3. **Прикрепленные файлы (Attachments) и Lightbox:**
     - Хранение файлов на диске в `uploads/org_<id>/` (вне `public/`), метаданные в таблице `organization_files` (`id`, `org_id`, `filename`, `original_name`, `mime_type`, `file_size`, `uploaded_by`, `created_at`).
     - Разрешенные форматы: `.xlsx`, `.xls`, `.csv`, `.pdf`, `.docx`, `.doc`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.txt`, `.zip`, `.rdp` (до 25 МБ).
     - Компактные плитки-чипсы с цветными иконками по типу файла, размером, кнопками скачивания и удаления.
     - Встроенный Lightbox: модальное окно предпросмотра изображений и PDF прямо на странице без принудительной загрузки.
