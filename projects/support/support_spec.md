## 1. Контекст архитектуры и стек проекта

- **Backend:** Node.js 18+, Express 4.x, EJS-шаблоны, Vanilla JavaScript (ES6+), SheetJS (`xlsx`) для парсинга таблиц.
- **Стилизация:** CSS3 Custom Properties (дизайн-токены), адаптивная верстка (Flexbox/Grid), поддержка темной и светлой тем (`data-theme="dark"` / `light`).
- **База данных (Dual-Engine):**
  - **Production (Plesk):** MariaDB/MySQL (`p-14802_wiki`) через пул `mysql2/promise` с параметризованными запросами (`?`), кодировка `utf8mb4`.
  - **Development (Local):** In-memory мок `db-stub.js` при `DB_STUB=true` (логин: `admin` / `admin`).
- **Хранилище файлов:** Защищенная изолированная папка `uploads/org_<id>/` вне публичной статики `public/` с проверкой прав доступа сессии и защитой заголовками `X-Frame-Options: SAMEORIGIN`.

## 2. Регламент компонентов и UI-стандарты (Спринты 1–7)

### 2.1. Экран авторизации (`/login`)
* **Безопасность учетных данных:** Блок подсказки «Локальный доступ: admin / admin» отображается исключительно в локальном dev-окружении (`isStubMode === true`). На боевом хостинге Plesk подсказка скрыта.
* **Переключатель темы:** Контурная векторная SVG-кнопка (солнце/луна) с поддержкой темной и светлой темы.
* **Закрытый контур:** Публичная регистрация отключена (`/register` редиректит на `/login`). Двухшаговый сброс пароля встроен в карточку входа.

### 2.2. Карточка организации в Wiki (`/wiki`)
* **Аватар организации:** Автоматическая генерация монограммы из двух заглавных букв наименования компании (например, `АП` для Автоперекрестка, `AL` для ALPHUTA) в аккуратном блоке `44x44px` с фирменным сапфировым фоном.
* **Чистый лист заметок:** Моноширинный блок (`JetBrains Mono`, 15px) без программных номеров строк для комфортного выделения, чтения и копирования параметров доступов.
* **Экспорт:** Встроенный экспорт технической карточки компании в PDF (через системный диалог печати) и чистый TXT.
* **Легендарная красная булавка 📌:** Каждая компания в сайдбаре может быть закреплена персонально для текущего пользователя. Закрепленные компании поднимаются в секцию «ЗАКРЕПЛЕННЫЕ» вверху списка.
* **Прикрепленные файлы:**
  * Компактная кнопка `+` в заголовке секции для быстрого добавления вложений.
  * Чистый перечень файлов без лишних баннеров Drag & Drop.
  * Цветовая кодировка векторных SVG-иконок по типам (зеленый Excel, красный PDF, синий картинки, индиго документы, циан XML, янтарный архивы).
  * Корректная кириллическая кодировка русских имен файлов (без артефактов `ÐºÐ¾Ð½ÑÑÑ`).
* **WhatsApp-like Lightbox Предпросмотр:**
  * `.xlsx`, `.xls`, `.csv`: парсинг SheetJS с интерактивным отображением таблицы ячеек со sticky-заголовком и переключением листов прямо в модальном окне.
  * `.xml`, `.txt`: чистый блок форматированного кода с подсветкой.
  * `.pdf`: отображение через iframe без ошибок благодаря `X-Frame-Options: SAMEORIGIN`.
  * Изображения: адаптивный просмотр картинки с блюр-бэкдропом.

### 2.3. Главная страница (Дашборд `/`)
* **Широкий экранный контейнер:** Ограничение рабочей области `max-width: 1320px; width: 100%; margin: 0 auto;`.
* **Масштабная Hero-карточка «Wiki» (1320px):**
  * Слева: сапфировая иконка базы знаний, заголовок `Wiki — Серверная база знаний` (30px), солидное 2-абзацное описание, единственный чистый динамический тег `<%= totalServers %> организаций` и акцентная кнопка «Перейти в базу знаний →».
  * Справа: отцентрированная детализированная векторная SVG-иллюстрация серверной стойки без перегружающих списков.

## 3. Архитектурные решения (ADR)

### ADR-006: Закрытая регистрация, двухшаговый сброс пароля и Rate Limiting (без блокировки по IP)
* **Статус:** Принято / Реализовано (Спринт 7)
* **Решение:**
  1. Полное отключение маршрутов `/register`, удаление ссылок и форм регистрации.
  2. Двухшаговый сброс пароля на `/login`: верификация логина (`POST /api/auth/verify-login`) → новый пароль с подтверждением (`POST /api/auth/reset-password`).
  3. In-memory Rate Limiter: ограничение до 5 неудачных попыток за 15 минут с одного IP (HTTP 429).
  4. Security Hardening: `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: same-origin`, куки `httpOnly: true`, параметризованные SQL-запросы (`?`).

### ADR-007: Масштабный Hero-дашборд (1320px), легендарная красная булавка 📌 и вложения файлов с WhatsApp-like предпросмотром
* **Статус:** Принято / Реализовано (Спринт 7)
* **Решение:**
  1. **Hero-дашборд 1320px:** Рабочий контейнер расширен до 1320px. В левой колонке оставлен только динамический бейдж количества организаций, в правой — отцентрированная векторная иллюстрация серверной стойки.
  2. **Персональное закрепление (Легендарная красная булавка 📌):** Таблица `user_pins` (`user_id`, `org_id`) и методы в `db-stub.js`. В сайдбаре отображается классическая красная булавка 📌 с группировкой вверху списка.
  3. **Прикрепленные файлы и кодировка:**
     - Хранение в `uploads/org_<id>/`, таблица `organization_files` (`DEFAULT CHARSET=utf8mb4`).
     - Хелпер `fixUtf8Filename` устраняет повреждение кодировки UTF-8 в Multer/Busboy.
     - Кнопка `+` без дублирования, удаление Drag & Drop баннера в пользу чистого перечня.
     - Добавлена поддержка формата `.xml`.
  4. **WhatsApp-like Lightbox Предпросмотр:**
     - Эндпоинт `GET /api/files/:fileId/preview` на базе `xlsx` (SheetJS) генерирует HTML-таблицу для `.xlsx`, `.xls`, `.csv` с переключением вкладок листов.
     - Просмотр `.xml` и `.txt` в блоке кода.
     - `X-Frame-Options: SAMEORIGIN` обеспечивает безотказное открытие PDF-документов в iframe без ошибки подключения.
