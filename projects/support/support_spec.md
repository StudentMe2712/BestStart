## 1. Регламент компонентов и UI-стандарты (Спринт 6)

### 1.1. Экран авторизации (`/login`)
* **Безопасность учетных данных:** Блок подсказки «Локальный доступ: admin / admin» отображается исключительно в локальном dev-окружении (`isStubMode === true`). На боевом хостинге Plesk рендеринг заблокирован.
* **Переключатель темы:** Контурная векторная SVG-кнопка (солнце/луна) с поддержкой темной и светлой темы.

### 1.2. Карточка организации в Wiki (`/wiki`)
* **Аватар организации:** Автоматическая генерация монограммы из двух заглавных букв наименования компании (например, `АП` для Автоперекрестка, `AL` для ALPHUTA) в аккуратном блоке `44x44px` с фирменным синим фоном.
* **Табы компании:** Замена цветных эмодзи на монохромные векторные SVG-иконки (документ для «Данных», куб для «Баз 1С»).
* **Текстовые заметки:** Отображение в свободном моноширинном блоке (`JetBrains Mono`, 15px) без программных номеров строк для комфортного выделения и копирования текста.
* **Модальное окно базы:** Обязательный атрибут `autocomplete="off"` на всех инпутах для предотвращения наложения браузерной истории. Кнопка «Сохранить» оформлена в фирменном сапфировом стиле (`--brand-primary`).

### 1.3. Журнал «События» (`/events`)
* **Фильтрация пустых строк:** По умолчанию отображаются только организации, имеющие хотя бы 1 привязанную базу 1С. Пользователь избавлен от необходимости скроллить десятки строк с пометкой `0 баз`.
* **Ограничение ширины:** Контейнер таблицы ограничен `max-width: 1400px` для исключения разрыва между названием базы и датой на 2K/4K экранах.
* **Навигация:** Иконка перехода `↗` снабжена информативным тултипом «Перейти в карточку компании в Wiki».

### 1.4. Главная страница (Дашборд `/`)
* **Симметрия карточек:** Карточка «Wiki» содержит бейдж `25 организаций`, карточка «События» — симметричный бейдж общего количества баз (`N баз 1С`).
* **Верстка:** Удален артефакт верхней синей полоски, контент центрирован, увеличены внутренние отступы карточек.
