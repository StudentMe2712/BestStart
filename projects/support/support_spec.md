## 1. Концепция и архитектура разделов

### 1.1. Карточка компании (Wiki)
В рабочей области организации контент разделен на две вкладки (табы):
1. **Вкладка «Данные»:** Свободные текстовые заметки администраторов (AnyDesk, RDP, учетные записи, дисковые массивы, iLO) с комфортной моноширинной типографикой.
2. **Вкладка «Базы 1С»:** Таблица привязанных информационных баз компании.
   * Поля базы: `Информационная база` (имя), `Описание` (свободный текст: релиз, конфигурация, специфика), `Дата` (дата обновления).
   * Возможность добавления, редактирования и удаления баз.

### 1.2. Раздел «События» (Иерархический журнал 1С)
* **Архитектурный паттерн:** Дерево значений / Иерархический список (по аналогии с 1С).
* **Группировка:** Строка верхнего уровня — Организация (с иконкой шеврона и счетчиком баз). При клике раскрываются вложенные строки баз.
* **Табличная структура:**
  * Колонка 1: **Организация** (строка-родитель)
  * Колонка 2: **Информационная база** (дочерняя строка)
  * Колонка 3: **Описание** (релиз / комментарий)
  * Колонка 4: **Дата** (дата фиксации)
* Предотвращает разрастание списка при большом количестве клиентов и баз.

### 1.3. Главная страница (Дашборд)
* Верхняя плашка: приветствие с логином пользователя (`<%= user.username %>`), заголовок **«База знаний ИТС-Ком»**, актуальная дата на русском языке.
* Две крупные сбалансированные карточки без лишних буллетов:
  * **Wiki:** *«Технические параметры серверов, доступы и конфигурации.»*
  * **События:** *«Иерархический журнал и реестр информационных баз 1С.»*

## 2. Архитектурные решения (ADR)

* **ADR-001: Локальный In-Memory Mock (`db-stub.js`):** Автономная работа локально без MariaDB (`DB_STUB=true`, вход `admin / admin`).
* **ADR-002: Двухсекционная карточка организации:** Разделение на вкладки «Данные» (свободные заметки) и «Базы 1С» (учет конфигураций со свободным полем описания).
* **ADR-003: Иерархическое дерево в «Событиях»:** Реализация аккордеона по организациям для компактного отображения реестра баз.
* **ADR-004: Безотказный экспорт PDF:** Переход с нестабильного Puppeteer на оптимизированный печатный HTML-шаблон с авто-вызовом `window.print()`.
