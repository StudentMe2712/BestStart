## 1. Контекст архитектуры и стек проекта

- **Backend:** Node.js 18+, Express 4.x, EJS-шаблоны, Vanilla JavaScript (ES6+), SheetJS (`xlsx`) для электронных таблиц, `mammoth` для конвертации документов `.docx` в HTML.
- **Стилизация:** CSS3 Custom Properties (дизайн-токены), адаптивная верстка (Flexbox/Grid), поддержка темной и светлой тем (`data-theme="dark"` / `light`).
- **База данных (Dual-Engine):**
  - **Production (Plesk):** MariaDB/MySQL (`p-14802_wiki`) через пул `mysql2/promise` с параметризованными запросами (`?`), кодировка `utf8mb4`.
  - **Development (Local):** In-memory мок `db-stub.js` при `DB_STUB=true` (логин: `admin` / `admin`).
- **Хранилище файлов:** Защищенная изолированная папка `uploads/org_<id>/` вне публичной статики `public/` с проверкой прав доступа сессии и заголовками `X-Frame-Options: SAMEORIGIN`.

## 2. Регламент компонентов и UI-стандарты (Спринты 1–7)

### 2.1. Экран авторизации (`/login`)
* **Безопасность учетных данных:** Блок подсказки «Локальный доступ: admin / admin» отображается исключительно в локальном dev-окружении (`isStubMode === true`). На боевом хостинге Plesk подсказка скрыта.
* **Переключатель темы:** Контурная векторная SVG-кнопка (солнце/луна) с поддержкой темной и светлой темы.
* **Закрытый контур:** Публичная регистрация отключена (`/register` редиректит на `/login`). Двухшаговый сброс пароля встроен в карточку входа.

### 2.2. Карточка организации в Wiki (`/wiki`)
* **Аватар организации:** Автоматическая генерация монограммы из двух заглавных букв наименования компании (например, `АП` для Автоперекрестка, `AL` для ALPHUTA) в аккуратном блоке `44x44px` с фирменным сапфировым фоном.
* **Чистый лист заметок:** Моноширинный блок (`JetBrains Mono`, 15px) без программных номеров строк для комфортного копирования параметров доступов.
* **Экспорт:** Встроенный экспорт технической карточки компании в PDF (печать) и чистый TXT.
* **Умная красная булавка 📌 (Smart Pin):**
  * По умолчанию булавка у незакрепленных компаний скрыта (`opacity: 0`), исключая визуальный шум.
  * Плавно проявляется при наведении курсора (`:hover`) и клавиатурном фокусе (`:focus-within`) на строку организации.
  * У закрепленных компаний булавка видна постоянно (`.is-pinned`), поднимая организацию в верхнюю подгруппу «ЗАКРЕПЛЕННЫЕ».
  * Поддерживает сенсорные экраны (`@media (hover: none)`).
* **Прикрепленные файлы:**
  * Компактная кнопка `+` без дублирования текста.
  * Чистый перечень файлов без лишних баннеров Drag & Drop.
  * Общая доступность: любой авторизованный сотрудник видит все вложения организации и может скачивать или удалять как свои, так и чужие файлы.
  * Цветовая кодировка векторных SVG-иконок по типам (зеленый Excel, красный PDF, синий Word/DOCX, голубой картинки, циан XML, янтарный архивы).
  * Корректная кириллическая кодировка русских имен файлов (без артефактов `ÐºÐ¾Ð½ÑÑÑ`).
* **Полнофункциональный Lightbox Предпросмотр:**
  * `.docx`: рендеринг отформатированного документа HTML через библиотеку `mammoth` в стилизованном блоке чтения `.lightbox-doc-wrap`.
  * `.doc`: презентационная карточка документа Word с кнопкой быстрого скачивания.
  * `.xlsx`, `.xls`, `.csv`: интерактивная таблица ячеек SheetJS с фиксированным заголовком и вкладками листов.
  * `.xml`, `.txt`: чистый блок форматированного кода с подсветкой синтаксиса.
  * `.pdf`: безотказное отображение через iframe без ошибок благодаря `X-Frame-Options: SAMEORIGIN`.
  * Изображения (`.png`, `.jpg`, `.jpeg`, `.webp`): просмотр в исходном качестве 1:1, четкий рендеринг (`-webkit-optimize-contrast`), кнопка масштаба `1:1` и зум по клику на картинку с панорамированием.

### 2.3. Единый диалог подтверждения удаления (Unified Confirm Modal)
* Полный отказ от нативных браузерных окон `confirm()` и `alert()`.
* Модальный диалог `#unifiedConfirmModal`:
  * Элегантный оверлей с эффектом размытия (backdrop-filter blur).
  * Четкий заголовок, краткое описание с выделением имени удаляемого объекта в бейдж.
  * Визуальное предупреждение о необратимости операции.
  * Кнопка «Отмена» и акцентная красная кнопка подтверждения с анимированным спиннером и блокировкой повторных кликов на время выполнения запроса.
  * Доступность: закрытие по Escape, клику по оверлею (клики внутри окна изолированы), возврат фокуса.
  * Ненавязчивые toast-уведомления об успехе или ошибке.

### 2.4. Главная страница (Дашборд `/`)
* **Широкий экранный контейнер:** Ограничение рабочей области `max-width: 1320px; width: 100%; margin: 0 auto;`.
* **Масштабная Hero-карточка «Wiki» (1320px):**
  * Слева: сапфировая иконка базы знаний, заголовок `Wiki — Серверная база знаний` (30px), солидное 2-абзацное описание, единственный чистый динамический тег `<%= totalServers %> организаций` и акцентная кнопка «Перейти в базу знаний →».
  * Справа: идеально отцентрированная векторная SVG-иллюстрация серверной стойки без перегружающих списков.

## 3. Архитектурные решения (ADR)

### ADR-006: Закрытая регистрация, двухшаговый сброс пароля и Rate Limiting (без блокировки по IP)
* **Статус:** Принято / Реализовано (Спринт 7)
* **Решение:** Маршруты регистрации закрыты, 2-шаговый сброс по логину, in-memory Rate Limiter (5 попыток за 15 минут), заголовки безопасности.

### ADR-007: Масштабный Hero-дашборд (1320px), файлы и WhatsApp-like Lightbox
* **Статус:** Принято / Реализовано (Спринт 7)
* **Решение:** Расширение дашборда до 1320px, хранилище `uploads/org_<id>/`, таблица `organization_files` (`utf8mb4`), исправление русских имен файлов, SheetJS/XML превью.

### ADR-008: Поддержка Word DOCX/DOC, 1:1 Image Preview, общий доступ, Unified Confirm Modal и Smart Pin
* **Статус:** Принято / Реализовано (Спринт 7)
* **Решение:**
  1. **Документы Word (.docx, .doc):** Внедрена библиотека `mammoth` для конвертации `.docx` в чистый HTML. Предусмотрен `doc_fallback` для устаревших `.doc`.
  2. **Исходное качество изображений 1:1:** Бинарная отдача без пережатия, курсор-лупа и кнопка `1:1` в Lightbox с переключением между подгонкой под экран и 100% масштабом пикселей.
  3. **Общий доступ к файлам:** Просмотр и удаление вложений доступны любому авторизованному инженеру (без ограничений по автору загрузки).
  4. **Unified Confirm Modal:** Создан единый кастомный модальный компонент `#unifiedConfirmModal`, полностью устранивший все нативные вызовы `confirm()` в проекте.
  5. **Умная булавка Pin:** Скрытие булавки у незакрепленных компаний по умолчанию, плавное появление по `:hover` / `:focus-within` без сдвига верстки строки, постоянная видимость для закрепленных.
