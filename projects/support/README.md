## ⚡ Быстрый старт (Локальная разработка)

Проект полностью автономен и не требует развертывания локальной MariaDB/MySQL базы благодаря встроенному In-Memory Mock Stub (`db-stub.js`).

### Запуск в 1 клик на Windows:
```cmd
start-local.bat
```

### Запуск через терминал:
```bash
npm install
npm run start:local
```

### Доступ по умолчанию:
* **URL:** [http://localhost:3000](http://localhost:3000)
* **Логин:** `admin` (или `AdminITS`)
* **Пароль:** `admin` (или `admin123`)
* **Автозаполнение:** клик по плашке `Локальный доступ: admin / admin` на странице входа.

## 🛠 Ключевой функционал

1. **База знаний Wiki (`/wiki`):**
   - Удобная навигация по 25+ организациям с мгновенным поиском.
   - **Таб «Данные»:** Свободные заметки по серверной инфраструктуре (AnyDesk, RDP, СУБД, iLO) с комфортной моноширинной типографикой (`JetBrains Mono`, 15px, line-height 1.6) и номерами строк.
   - **Таб «Базы 1С»:** Реестр информационных баз со свободным вводом описания (`3.0.73.1 (БК), подсистема Строительство`), датой фиксации и AJAX CRUD.
   - Редактирование текста без ломки верстки с автосохранением черновика.

2. **Иерархический журнал релизов 1С — «События» (`/events`):**
   - Классическое дерево значений в стиле 1С:Предприятие 8.3.
   - Все компании по умолчанию свернуты.
   - Квадратные узлы раскрытия `[+]` ⇄ `[-]`.
   - Организации с 0 баз отображаются компактно без плюсиков и серых заглушек.

3. **Лаконичный Дашборд (`/`):**
   - Персонализированное приветствие `С возвращением, <логин>`, дата на русском языке, статус узлов.
   - Две сбалансированные карточки Wiki и Событий строго по 1 предложению, без перегруза буллетами.

4. **Безотказный экспорт (меню «Ещё»):**
   - **PDF:** Printable HTML View с `@media print` и авто-вызовом `window.print()` для печати и сохранения без падений Puppeteer.
   - **TXT:** Чистый структурированный файл заметок и перечня баз 1С.
