# Web Memory 🧠

Chrome-расширение (Manifest V3), которое сохраняет **важные фрагменты внутри страниц**, а
не страницы целиком. Выделите абзац — и вернётесь к нему через неделю за 1 клик.

Всё хранится **локально** (IndexedDB). Без облака, без регистрации, offline-first.

## Что умеет MVP

1. **Запомнить место** — выделите текст → плавающая панель (или контекстное меню) →
   фрагмент сохраняется и **автоматически подсвечивается** при повторном открытии страницы.
2. **Заметки** — к выделению (`📝`) или к произвольному элементу страницы
   (`📌 Прикрепить заметку к элементу`). Заметки видны при следующем визите (подсветка / пин).
3. **Side Panel** — основной интерфейс: «Эта страница» и «Моя память».
4. **Полнотекстовый поиск** (FlexSearch) по фрагментам, заметкам и заголовкам страниц.

Отмечать важным — `⭐`. Открыть панель — клик по иконке расширения.

> Отложено для v1 (по приоритету): синхронизация, облако, AI, режим чтения, офлайн-архив,
> прогресс чтения, всплывающий popup.

## Технологии

- **WXT** (фреймворк web-расширений, MV3) + **Vite**
- **React 18** + **TypeScript** + **Tailwind CSS**
- **IndexedDB** через `idb` — хранилище
- **FlexSearch** — полнотекстовый поиск
- Подсветка: собственный **text-quote**-якорь (exact + prefix/suffix + offset), как в W3C
  Web Annotation — устойчив к повторному открытию страницы.

## Архитектура (важно)

Content-script работает в origin **страницы** и не имеет доступа к IndexedDB **расширения**.
Поэтому:

```
 страница (content script)              расширение
 ┌───────────────────────────┐         ┌───────────────────────────┐
 │ выделение → anchor         │ message │ background SW             │
 │ подсветка / пины (React в  │ ──────► │ ── единственный владелец  │
 │ shadow root)               │ ◄────── │    IndexedDB (memories)   │
 └───────────────────────────┘         └───────────┬───────────────┘
                                                    │ messages
                                          ┌─────────▼─────────┐
                                          │ Side Panel (React)│
                                          │ список + поиск    │
                                          └───────────────────┘
```

- **background** (`entrypoints/background.ts`) — владелец IndexedDB, контекстные меню,
  открытие side panel по клику на иконку, «открыть и проскроллить» для переходов между
  страницами.
- **content** (`entrypoints/content/`) — повторное наложение подсветки на загрузке, захват
  выделения, плавающая панель, режим выбора элемента, пины (React в shadow root).
- **sidepanel** (`entrypoints/sidepanel/`) — список «Эта страница», глобальная «Моя память»,
  поиск, переход/редактирование/удаление.
- **lib/** — общий контракт: `types`, `messages`, `db` (idb), `anchor` (якоря),
  `highlight` (DOM-подсветка), `search` (FlexSearch), `url`.

## Запуск

> Сборка требует Node ≥ 18 и установки npm-зависимостей.

```bash
npm install          # ставит зависимости + wxt prepare (генерирует .wxt/)
npm run dev          # запуск в режиме разработки (Chrome, HMR)
npm run build        # production-сборка → .output/chrome-mv3/
npm run compile      # проверка типов (tsc --noEmit)
```

### Загрузить в Chrome (без Store)

1. `npm run build`
2. Откройте `chrome://extensions`, включите **Developer mode**.
3. **Load unpacked** → выберите папку `.output/chrome-mv3`.
4. Откройте любой сайт, выделите текст — появится панель «Запомнить». Клик по иконке
   расширения открывает боковую панель.

Для Firefox: `npm run build:firefox` → `.output/firefox-mv2`.
