# Design System — Визуальная система и дизайн-токены Second Self

**Документ:** `01_UX_UI/Design_System.md`
**Этап:** 2. UX/UI-спецификация
**Статус:** Версия 1.0 (На согласовании)

## 1. Визуальная философия: Warm Glassmorphism

Дизайн-система **Second Self** построена на сочетании двух визуальных настроений из эталонных референсов:
1. **Тёплое матовое стекло (Compact Mode — референс `image_7ebeda.jpg`):** полупрозрачные карточки с медным и янтарным свечением, мягко пропускающие свет обоев рабочего стола. Виджет выглядит как тактильный предмет интерьера, а не как системное окно Windows.
2. **Глубокий обсидиановый фокус (Expanded Mode & Player — референсы `image_7ebe7e.jpg`, `image_7ebe42.jpg`):** при раскрытии панели и просмотре видео фон уплотняется до глубокого тёмно-угольного оттенка (`#0D0D0F`), чтобы обеспечить безупречный контраст для чтения задач, кинематографичную подачу видеокадра и чёткую считываемость янтарной шкалы прогресса.

### Три правила визуальной гигиены
* **Никакого визуального шума:** в один момент времени на экране видны только необходимые контролы. Второстепенные действия (редактирование, удаление задачи) скрыты до клика или наведения.
* **Тёплый свет вместо холодного неона:** никаких кислотно-синих или тревожно-красных оттенков. Основные акценты — тёплый терракотово-янтарный (`#D2844A`) и спокойный изумрудно-зелёный (`#34D399`) для индикации готовности и успеха.
* **Световой контур (Specular Rim):** вместо грубых сплошных рамок карточки очерчены тонкой (`1px`) полупрозрачной линией с бликом в верхнем левом углу, создающим ощущение толщины стекла.

## 3. Типографика и шрифтовая шкала (Typography Scale)

Используется гарнитура **`Segoe UI Variable Display` / `Segoe UI Variable Text`** (стандарт Windows 11) с автоматическим фоллбэком на встроенный в пакет приложения шрифт **`Inter`** для идентичного отображения на Windows 10.
Для всех числовых счётчиков, процентов и таймкодов обязательно включается свойство табличных цифр (`FontNumeralAlignment="Tabular"` / `tnum`), чтобы при тикании секундомера плеера строка `01:42 / 01:42` не дрожала по ширине.

| :--- | :--- | :--- | :--- | :--- |

## 4. Геометрия, сетка, скругления и тени

### 4.1. Модульная сетка и отступы (Spacing System)
Базовая единица сетки — **`4px`**. Все внутренние поля и зазоры кратны `4px`:
* `Space.XS = 4px` (зазор между заголовком секции и подзаголовком *Your daily direction*).
* `Space.SM = 8px` (вертикальный шаг между капсулами задач в компактном режиме).
* `Space.MD = 12px` (зазор между карточками в компактном режиме; отступ от превью видео до заголовка *Your daily video*).
* `Space.LG = 16px` (внутренний отступ строки задачи; расстояние между элементами внутри секции).
* `Space.XL = 20px` (внутренний отступ `Padding` от краёв окна раскрытого виджета до контента).
* `Space.XXL = 24px` (отступ между крупными секциями в Personal Dashboard).

### 4.2. Радиусы скругления (`CornerRadius`)

| Элемент интерфейса | Радиус скругления | Примечание по геометрии |
| :--- | :--- | :--- |
| Внешний контейнер окна виджета (Expanded / Player) | `20px` | С тонкой внешней обводкой `1px` |
| Крупные стеклянные карточки (Compact Mode) | `24px` | Глубокое органичное скругление как на референсе `image_7ebeda.jpg` |
| Контейнер видео / превью кадра (`Daily Reset`) | `14px` | Вписан внутрь секции с отступом `20px` от краёв окна |
| Кнопка действия «Засчитать выполнение» | `10px` | Высота кнопки `44px` на всю ширину контейнера плеера |
| Капсулы задач в компактном виджете | `18px` (`Pill`) | Высота капсулы `36px` |
| Статусные бейджи (`Ready`, `Completed playback`) | `999px` (`Full Pill`) | Высота `22px`, горизонтальный `Padding: 10px` |
| Линия прогресса месяца и видео | `4px` | Высота трека `6px` |

### 4.3. Тени и глубина (`Elevation`)
* **`Elevation.Widget.Ambient`:** `Offset(0, 16px)`, `BlurRadius = 48px`, `Color = rgba(0, 0, 0, 0.55)` — мягкая глубокая тень под плавающим виджетом, отделяющая его от любых обоев рабочего стола.
* **`Elevation.Card.Subtle`:** `Offset(0, 4px)`, `BlurRadius = 16px`, `Color = rgba(0, 0, 0, 0.28)` — тень карточек внутри Dashboard.

## 5. Иконографика и базовые UI-компоненты

### 5.1. Стандарт иконок (SVG / Lucide)
* Набор: **Lucide Icons** (векторные `PathIcon` / `SvgImageSource`).
* Размерная сетка:
  * `16x16px` — чекбоксы задач, иконки действий (`Check`, `Edit`, `Trash`), иконка динамика громкости в плеере, галочка внутри кнопки «Засчитать выполнение».
  * `20x20px` — круглая кнопка добавления задачи `+`, кнопка запуска видео `Play`, стрелка сворачивания виджета.
* Толщина штриха: `1.75px`, скруглённые окончания (`StrokeLineCap="Round"`, `StrokeLineJoin="Round"`).

### 5.2. Спецификация ключевых атомарных контролов

1. **Чекбокс и строка задачи (`TaskRowControl`):**
   * Слева: круглое кольцо `18x18px` (`Stroke: rgba(255,255,255,0.28)`, `1.5px`). В состоянии `Done` кольцо заполняется белым или изумрудным контуром с галочкой внутри.
   * По центру: текст задачи (`14px`), при выполнении — анимированная линия зачёркивания.
   * Справа: кнопка `...` (`MoreHorizontal`), которая по клику плавно трансформируется в горизонтальную группу из 3 SVG-иконок (`Check`, `Edit`, `Trash`) с шагом `8px` и всплывающими `ToolTip` через `300ms` наведения.
2. **Бейдж статуса (`StatusBadgeControl`):**
   * Компактная капсула в правом верхнем углу секции *Daily Reset*.
   * Состояния: `Ready` (зелёный текст `#36D399` на фоне `rgba(38, 166, 91, 0.18)`), `Paused` (янтарный `#F59E0B`), `Completed playback` (зелёный `#36D399`).
3. **Индикатор прогресса месяца (`MonthlyProgressBar`):**
   * Фоновый трек: `rgba(255, 255, 255, 0.12)`, высота `6px`, скругление `3px`.
   * Заполняющая полоса: сплошной тёплый янтарь `#CE824C`, ширина анимируется пропорционально проценту $P \in [0..100]$.
4. **Кнопка фиксации ритуала (`ConfirmRitualButton`):**
   * Появляется только в состоянии `Completed playback` (референс `image_7ebe42.jpg`).
   * Фон: `#C8824B`, высота `44px`, скругление `10px`, по центру иконка круглой галочки `16px` + текст **«Засчитать выполнение»** (`14px SemiBold`, `#FFFFFF`).

## 6. Система движения и анимаций (Motion System)

Все анимации выполняются на уровне **WinUI Composition Layer (60–120 FPS)** без блокировки UI-потока.

| Анимационный сценарий | Длительность | Кривая ускорения (`CubicBezier`) | Описание движения |
| :--- | :--- | :--- | :--- |
| **Раскрытие / сворачивание виджета** | `280ms` | `(0.16, 1.0, 0.3, 1.0)` — *Spring Out* | Плавное изменение высоты и ширины окна с кросс-фейдом (`Opacity`) карточек компактного и раскрытого состояния |
| **Появление панели из 3 иконок задачи** | `180ms` | `(0.25, 1.0, 0.5, 1.0)` | Иконка `...` уходит в `Opacity 0`, а 3 иконки действий выезжают справа налево на `8px` |
| **Выполнение задачи (Strikethrough + Fade)** | `700ms` (2 фазы) | Фаза 1 (`350ms`): линия зачёркивания и `Opacity -> 0.45`. Фаза 2 (`350ms`): схлопывание высоты строки `Height -> 0` | Даёт глазу зафиксировать удовольствие от закрытия задачи без искусственных зависаний интерфейса |
| **Появление кнопки «Засчитать выполнение»** | `320ms` | `(0.16, 1.0, 0.3, 1.0)` | Мягкий подъём кнопки снизу вверх (`TranslateY: +12px -> 0px`) одновременно с набором `Opacity: 0 -> 1` |
| **Тост отмены действия (`Undo Toast`)** | `200ms` вход / `5000ms` удержание / `200ms` выход | `(0.2, 0.8, 0.2, 1.0)` | Ненавязчивая плашка в нижней части блока *Today's Focus* |
