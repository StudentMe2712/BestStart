# Widget Specification — Спецификация Desktop Widget и Видеоплеера

**Документ:** `01_UX_UI/Widget_Specification.md`
**Этап:** 2. UX/UI-спецификация
**Статус:** Версия 1.0 (На согласовании)

## 1. Архитектурная модель окна Desktop Widget

Desktop Widget функционирует как **единое окно WinUI 3** (`Microsoft.UI.Xaml.Window`) с прозрачным фоном (`SystemBackdrop = Transparent`) и кастомным хромом (без стандартного системного заголовка Windows).

### 1.1. Базовые параметры окна и флаги Win32 Interop
* **Стиль окна:** безрамочное (`WS_POPUP`), с включённым сглаживанием прозрачности `DwmExtendFrameIntoClientArea`.
* **Позиционирование:** `WS_EX_TOOLWINDOW` (не загромождает переключатель `Alt+Tab`) и `WS_EX_TOPMOST` (поверх окон в соответствии с настройкой *Pin on top*).
* **Виртуальные рабочие столы:** интеграция с `IVirtualDesktopManager` — окно автоматически отображается на всех виртуальных рабочих столах Windows 10/11 (`PinWindow`).
* **Точка привязки трансформации:** правый верхний угол (`Top-Right Anchor`) — при раскрытии вниз и влево окно гармонично увеличивается относительно своего положения на экране.

## 2. Компактный режим (Compact Mode)

### 2.1. Геометрия и компоновка
* **Габариты контейнера окна:** `360px` (ширина) $\times$ `240px` (высота).
* **Композиция:** асимметричная двухколоночная сетка из 3 стеклянных карточек (референс `image_7ebeda.jpg`).

```text
┌───────────────────────┬────────────────────────┐
│  Карточка 1           │  Карточка 2            │
│  Today's Focus        │  Daily Reset (Превью)  │
│  (170px × 240px)      │  (178px × 140px)       │
│                       ├────────────────────────┤
│  • Buy groceries      │  Карточка 3            │
│  • Workout            │  Quick Hub / Progress  │
│  • Check Portfolio    │  (178px × 88px)        │
└───────────────────────┴────────────────────────┘
```

### 2.2. Карточка 1: Today's Focus (Левая колонка)
* **Размер:** `170px` (ширина) $\times$ `240px` (высота), `CornerRadius = 24px`.
* **Фон:** `Surface.Widget.Compact.WarmGlass` (`rgba(156, 82, 43, 0.44)`), `BackdropBlur = 32px`, световая кромка `Border.Glass.Specular`.
* **Внутренний отступ (`Padding`):** `16px`.
* **Элементы:**
  * Заголовок: *Today's Focus* в две строки (`Type.Widget.CompactTitle`, `22px Medium`, `#FFFFFF`).
  * Кнопка быстрого добавления (`+`): круглая полупрозрачная кнопка `28x28px` в правом верхнем углу карточки (`Surface.Control.Pill`). По клику открывает инлайн-поле быстрого ввода задачи прямо в карточке.
  * Список задач: до 3 видимых задач в виде тактильных капсул (`Height = 34px`, `CornerRadius = 17px`, фон `rgba(255, 255, 255, 0.08)`).
  * Содержимое строки задачи: мини-чекбокс `14x14px` слева + усечённый текст задачи (`12px Regular`, `TextTrimming = CharacterEllipsis`).
  * Поведение при наведении: плавное осветление фона капсулы до `rgba(255, 255, 255, 0.15)`.

### 2.3. Карточка 2: Daily Reset (Правая верхняя)
* **Размер:** `178px` (ширина) $\times$ `140px` (высота), `CornerRadius = 24px`.
* **Фон:** атмосферное превью кадра сегодняшнего видео с тёплым золотисто-янтарным тонированием.
* **Внутренний отступ (`Padding`):** `14px`.
* **Элементы:**
  * В правом верхнем углу: круглая кнопка `Share / Open` (`26x26px`, фон `rgba(255, 255, 255, 0.15)`).
  * В левом нижнем углу: надпись *Design Inspiration* / *Daily Reset* (`13px SemiBold`, `#FFFFFF`) и статусная подпись снизу *Update 2h ago* / *Ready* (`11px Regular`, `rgba(255, 255, 255, 0.7)`).
* **Поведение при клике:** запуск режима просмотра видео (открытие встроенного плеера).

### 2.4. Карточка 3: Quick Hub / Progress (Правая нижняя)
* **Размер:** `178px` (ширина) $\times$ `88px` (высота), `CornerRadius = 24px`.
* **Фон:** `Surface.Widget.Compact.DarkGlass` (`rgba(48, 34, 28, 0.62)`), `BackdropBlur = 28px`.
* **Внутренний отступ (`Padding`):** `12px 14px`.
* **Элементы:**
  * Стек миниатюр-обложек или индикатор месяца (*My Lectures / 3 new items* или *This Month: 78%*).
  * Служит триггером для раскрытия полного виджета или перехода в Personal Dashboard.

## 3. Раскрытый режим (Expanded Mode)

### 3.1. Геометрия и габариты
* **Габариты контейнера окна:** `380px` (фиксированная ширина) $\times$ `680px` (высота по умолчанию, динамически адаптируется от `580px` до `740px` при длинном списке задач).
* **Фон:** `Surface.Widget.Expanded.Bg` (`#0B0B0D` с прозрачностью `95%`), `BackdropBlur = 40px`, внешний контур `Border.Outer.Container` (`1px solid rgba(255, 255, 255, 0.12)`), `CornerRadius = 20px`.
* **Тень:** `Elevation.Widget.Ambient` (глубокое мягкое рассеивание `48px`).
* **Внутренний отступ окна (`Window Padding`):** `20px`.

### 3.2. Анатомия раскрытого виджета (Сверху вниз — референс `image_7ebe7e.jpg`)

#### Блок 1: Today's Focus (Список задач дня)
* **Заголовок:** строка из двух уровней текста:
  * Заголовок: `Today's Focus` (`16px SemiBold`, `#FFFFFF`).
  * Подзаголовок: `Your daily direction` (`12px Regular`, `rgba(255, 255, 255, 0.68)`).
  * Справа от заголовка: круглая кнопка добавления задачи `+` (`24x24px`, контур `1px`).
* **Список задач (`TaskListControl`):**
  * Максимум 3–5 видимых строк в нормальном состоянии (при превышении появляется кастомный ультратонкий скроллбар шириной `3px` цвета `rgba(255,255,255,0.15)`).
  * Высота строки задачи: `44px`, внутренний `Padding = 8px 12px`, `CornerRadius = 8px`.
  * Чекбокс слева: круглый контур `18x18px` (`rgba(255, 255, 255, 0.35)`). В отмеченном виде — белый контур с галочкой.
  * Текст задачи: `14px Regular`, `#FFFFFF`.
  * Кнопка действий справа: три точки `...` (`MoreHorizontal`, `16px`).
* **Разделитель:** горизонтальная линия `1px`, цвет `rgba(255, 255, 255, 0.07)`, отступ сверху и снизу `16px`.

#### Блок 2: Daily Reset (Карточка видео дня)
* **Заголовочная строка:**
  * Слева: заголовок секции `Daily reset` (`16px SemiBold`, `#FFFFFF`).
  * Справа: капсула статуса `StatusBadgeControl` (`Height = 22px`, `Padding: 4px 10px`, `CornerRadius = 11px`). Содержит текст `Ready` изумрудным цветом (`#36D399`) на полупрозрачной подложке.
* **Широкоформатный контейнер превью видео:**
  * Соотношение сторон: `16 : 9` (ширина `340px`, высота `191px`), `CornerRadius = 14px`.
  * Превью: кадр из видео (или атмосферное фото облаков и рассвета), с тёплым градиентным затемнением в нижней части для читаемости плашек.
  * В левом нижнем углу превью: полупрозрачная плашка источника/метки (`rawpixel.com` / `unsplash.com`, `Height = 20px`, `10px Regular`, капсула `rgba(0,0,0,0.5)`).
* **Нижняя полоса карточки видео:**
  * Слева: блок заголовка видео:
    * Заголовок: `Your daily video` (`14px SemiBold`, `#FFFFFF`).
    * Подзаголовок: `A moment to refocus` (`12px Regular`, `rgba(255, 255, 255, 0.68)`).
  * Справа: круглая кнопка воспроизведения `Play` (`28x28px`, белая векторная иконка на полупрозрачном фоне).

#### Блок 3: This Month (Прогресс месяца)
* **Заголовочная строка:**
  * Слева: заголовок секции `This month` (`16px SemiBold`, `#FFFFFF`).
  * Справа: числовой показатель совокупного процента `78%` (`20px Bold`, изумрудный цвет `#36D399`).
* **Горизонтальный прогресс-бар (`MonthlyProgressBar`):**
  * Трек: ширина `340px`, высота `6px`, скругление `3px`, цвет `rgba(255, 255, 255, 0.12)`.
  * Заполняющий бегунок: тёплый янтарь `#CE824C`, длина анимируется пропорционально проценту месяца.
* **Подписи метрик (Под прогресс-баром):**
  * Слева: `Daily 26/31` (`12px Regular`, `rgba(255, 255, 255, 0.68)`).
  * Справа: `Weekly 3/4` (`12px Regular`, `rgba(255, 255, 255, 0.68)`).
* **Нижний триггер сворачивания:**
  * По центру в самом низу окна виджета: аккуратная стрелка `ChevronUp` (`20px`, `rgba(255, 255, 255, 0.4)`), клик по которой плавно сворачивает панель обратно в компактный режим.

## 4. Спецификация экрана Видеоплеера (Daily Reset Player)

При клике на превью или кнопку `Play` виджет плавно трансформируется в экран полноэкранного фокус-плеера (референс `image_7ebe42.jpg`).

### 4.1. Габариты и композиция
* **Габариты окна:** сохраняются габариты раскрытого виджета (`380px × 680px`) либо плеер раскрывается в увеличенный комфортный формат `480px × 600px` в зависимости от соотношения сторон видео.
* **Фон:** монолитный глубокий графит `#0B0B0D`.

### 4.2. Состав элементов плеера (Сверху вниз)

1. **Верхняя строка состояния:**
   * Слева: заголовок `Daily Reset` (`16px SemiBold`, `#FFFFFF`).
   * Справа: бейдж текущего статуса:
     * В начале / в процессе: бейдж отсутствует или отображает `Playing`.
     * На паузе: бейдж `Paused` (янтарный `#F59E0B`).
     * В конце воспроизведения: бейдж `Completed playback` (зелёный `#36D399` на подложке `rgba(38, 166, 91, 0.18)`).
2. **Экран воспроизведения (Video Viewport):**
   * Скругление углов: `14px`, клиппинг краев видео.
   * Контроллер: `MediaPlayerElement` (Windows Media Playback).
   * Оверлей паузы: клик по самому видео ставит его на паузу / снимает с паузы.
   * Водяной знак источника в левом нижнем углу: капсула `unsplash.com` / `local`.
3. **Строка таймкода и громкости (Time & Audio Bar):**
   * Слева: табличный таймкод `01:42 / 01:42` (`12px Regular`, `FontNumeralAlignment = Tabular`, `rgba(255, 255, 255, 0.7)`).
   * Справа: иконка динамика `Volume2` (`16px`, клик включает/выключает звук `Mute`, при наведении раскрывается компактный мини-слайдер громкости).
4. **Полоса прогресса воспроизведения (Non-seekable Progress Bar):**
   * Трек: высота `4px`, цвет `rgba(255, 255, 255, 0.15)`.
   * Заполнение: сплошной янтарный `#CE824C`.
   * **Политика перемотки:** клики и перетаскивание курсором заблокированы (`IsHitTestVisible = false`).
5. **Финальная кнопка фиксации («Засчитать выполнение»):**
   * Появляется **только** после того, как текущий таймкод достиг финальной секунды (`Position >= NaturalDuration`).
   * Входная анимация: `TranslateY (+12px -> 0px)` + `Opacity (0 -> 1)` за `320ms`.
   * Размеры: ширина на всю строку (`100%`), высота `44px`, `CornerRadius = 10px`.
   * Фон: акцентный янтарь `#C8824B` (при наведении `#DE925C`, при нажатии `#B86E3B`).
   * Содержимое: иконка белой галочки в круге `CheckCircle2` (`16px`) + текст **«Засчитать выполнение»** (`14px SemiBold`, `#FFFFFF`).
   * Результат клика: начисление ритуала за день, обновление шкалы месяца, закрытие плеера с возвратом в раскрытый виджет со статусом `Completed`.

## 5. Спецификация переходов и состояний (State Matrix)

| Исходное состояние | Триггер / Событие | Целевое состояние | Анимация и трансформация |
| :--- | :--- | :--- | :--- |
| **Compact Mode** | Клик по карточке *Today's Focus* или *Quick Hub* | **Expanded Mode** | Окно меняет размер с `360x240` на `380x680` за `280ms`. Карточки компактного вида плавно растворяются (`Opacity -> 0`), блоки раскрытого вида проявляются (`Opacity -> 1`). |
| **Expanded Mode** | Клик по нижней стрелке свертывания / `Esc` / потеря фокуса | **Compact Mode** | Обратная плавная пружинная анимация сжатия окна за `240ms`. |
| **Expanded Mode** | Клик по кнопке `Play` или превью видео | **Daily Reset Player** | Блок задач и блок прогресса месяца мягко затухают, видеоконтейнер раскрывается на центральную позицию окна плеера за `220ms`. |
| **Player (Любой момент)** | Клик по крестику закрытия / `Esc` | **Expanded Mode** | Остановка воспроизведения с мгновенным сохранением `LastPositionMs` в БД, возврат в раскрытый виджет. Статус бейджа меняется на `Paused`. |
| **Любое состояние** | Запуск сторонней игры/видео во весь экран | **Hidden / Suspended** | Виджет снимает `TopMost` или временно скрывается с экрана. При выходе из полноэкранного режима плавно возвращается на экран за `300ms`. |
