# Second Self — Эталонная спецификация проекта (Master Spec)

**Версия документа:** 1.0 (Эталон / Single Source of Truth)
**Целевая платформа:** Windows 10 / 11 (x64 / ARM64)
**Технологический стек:** C# 14, .NET 10, WinUI 3 (Windows App SDK), WinUI Composition, Windows Media Playback, SQLite (Local-First)

## 1. Суть проекта и главный принцип

**Second Self** — автономное настольное приложение для Windows, объединяющее ненавязчивый плавающий виджет рабочего стола (**Desktop Widget**) и стратегическое пространство личных целей (**Personal Dashboard**).

> **Главный принцип Second Self:** Приложение не должно заставлять человека становиться лучше через блокировки, штрафы или искусственную геймификацию. Оно помогает не забывать о том, что пользователь сам решил стать лучше, мягко возвращая фокус к выбранным приоритетам.

Система опирается на три взаимосвязанных контура:

| Контур | Интерфейсное воплощение | Ключевой вопрос пользователя | Роль в системе |
| :--- | :--- | :--- | :--- |
| **Presence (Присутствие)** | Desktop Widget (Компактный и Раскрытый) | «На чём я держу фокус прямо сейчас?» | Постоянное, но ненавязчивое присутствие на рабочем столе, удерживающее задачи текущего дня и ежедневный ритуал перед глазами |
| **Direction (Направление)** | Personal Dashboard (Окно приложения) | «Куда я двигаюсь в горизонте 1–3 лет и зачем?» | Декомпозиция больших жизненных и профессиональных целей на понятные этапы (*Milestones*) и связка их с конкретными неделями |
| **Progress (Результат)** | Система расчёта и Monthly Recap | «Насколько честно я выполняю свои обязательства?» | Прозрачная математика месяца, отделяющая мелкую текучку от реальных шагов к большим целям |

## 2. Архитектурные и продуктовые инварианты (Канон проекта)

Перечисленные ниже 7 решений являются эталонными правилами проекта. Все последующие документы (`00_Product`, `01_UX_UI`, `02_Technical`, `03_Specification`, `04_Development`) обязаны строго соответствовать этой таблице без внутренних противоречий.

| Область | Зафиксированное эталонное правило |
| :--- | :--- |
| **1. Поведение виджета** | Единое окно WinUI 3 с двумя состояниями (**Compact** и **Expanded**). В компактном состоянии виджет отображается на всех виртуальных рабочих столах (`Win+Tab`). При клике раскрывается вниз с анимацией WinUI Composition. При потере фокуса (`Deactivated` / клик вне окна) или запуске полноэкранного приложения (игры, видео на весь экран) виджет автоматически сворачивается в компактный режим (или временно скрывается при Fullscreen-приложении). |
| **2. Трёхуровневая модель задач** | **Today's Focus (Задачи дня):** оперативная рутина (до 3–5 видимых карточек в фокусе). При выполнении с анимацией (600–800 мс + Undo 5 сек) уходит в Архив, но даёт **0%** в месячный рейтинг, чтобы исключить искусственную накрутку прогресса мелкими делами. **Daily Ritual (Видео-ритуал):** 1 видео в день из локальной библиотеки, даёт **30%** веса месяца. **Weekly Goal (Цель недели):** 1 главное обязательство на неделю, связанное с этапом Большой цели, даёт **70%** веса месяца. |
| **3. Логика видео и плеера** | Алгоритм выбора — **Shuffle-очередь без повторений** до исчерпания всей библиотеки. Выбранное видео жёстко фиксируется за текущими логическими сутками (`YYYY-MM-DD`) и не меняется при перезапусках приложения. Перемотка (Seek Bar) отключена; доступны пауза, громкость и закрытие с сохранением `LastPosition`. Автоматического зачёта нет — только по явному нажатию кнопки **«Засчитать выполнение»** после достижения конца ролика. Смена логических суток происходит в **04:00 утра**. Если файл видео повреждён или удалён с диска, система бесшовно берёт следующий валидный файл из очереди и помечает битый файл в Настройках. |
| **4. Математика прогресса (100%)** | Формула месяца: $P = 0.3 \times D + 0.7 \times W$, где $D = \frac{\text{Просмотренные дни}}{\text{Дней в месяце}} \times 100\%$, а $W = \frac{\text{Выполненные цели недель}}{\text{Недель в месяце (4 или 5)}} \times 100\%$. Принадлежность недели к месяцу определяется по правилу **ISO-8601 (четверг недели)**: если четверг падает на текущий месяц, вся неделя засчитывается в этот месяц (отсюда ровно 4 или 5 недель). После старта недели (понедельник 04:00) цель блокируется от «тихого редактирования»: её можно только выполнить, пропустить или отменить/перенести с явной записью в лог истории. |
| **5. Большие цели и этапы** | Одновременно активно **не более 4 Больших целей** (защита от распыления). Каждая Большая цель состоит из последовательных этапов (**Milestones**). Прогресс Большой цели двигается только при закрытии Этапа, а не автоматически от числа мелких задач. При создании *Weekly Goal* пользователь привязывает её к конкретному активному Этапу Большой цели. |
| **6. Экологичная статистика** | Отображаются только конструктивные метрики: **Monthly Score (%)**, прогресс **Daily Rituals (X / 28..31)**, прогресс **Weekly Goals (X / 4..5)**, счётчики Архива (*Сегодня / Неделя / Месяц*) и экран рефлексии **Monthly Recap** в конце месяца. Полный запрет на демотивирующие механики: никаких обнуляемых серий (streaks), штрафных баллов, красных экранов тревоги и почасовых трекеров времени. |
| **7. Надёжность и система** | Полная автономность (**100% Offline / Local-First**). Закрытие окна Dashboard переводит приложение в системный трей; виджет продолжает жить на рабочем столе. Автозапуск через реестр / Task Scheduler. Позиция виджета хранится относительно `MonitorID` в нормализованных координатах: при отключении внешнего монитора виджет автоматически перемещается в безопасную зону основного дисплея. Автоматический бэкап SQLite (`secondself.db`) раз в сутки с ротацией последних 14 копий. |

## 3. Архитектура файловой системы приложения (Runtime Layout)

В установленном виде пользовательские данные и медиафайлы хранятся изолированно и прозрачно:

```text
SecondSelf_AppData/
├── Data/
│   ├── secondself.db          # Основная база данных SQLite (WAL mode)
│   └── migrations.log         # Журнал применённых миграций схемы БД
├── Videos/                    # Локальная библиотека видео для Daily Reset
│   ├── video_001.mp4
│   └── ...
├── Thumbnails/                # Автоматически сгенерированные превью кадров ( кэш .webp / .jpg )
├── Backups/                   # Ежедневные снапшоты secondself_YYYYMMDD.db.bak
└── Settings/
    └── window_state.json      # Координаты виджета, MonitorID, DPI-масштаб, состояние сворачивания
```
