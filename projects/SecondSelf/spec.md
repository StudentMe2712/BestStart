## 1. Суть проекта и главный принцип

**Second Self** — премиальный десктопный инструмент для Windows, объединяющий элегантную выдвижную панель рабочего стола (**Desktop Drop-Down Widget**) и стратегическое пространство личных целей (**Personal Dashboard / Personal Space**).

> **Главный принцип Second Self:** Приложение не навязывает продуктивность через блокировки и штрафы, а мягко возвращает внимание к собственным решениям. Оно всегда под рукой, не спорит с окнами и ощущается как дорогой нативный системный инструмент (в духе Dynamic Island, macOS Control Center и Raycast).

## 2. Архитектурные и продуктовые инварианты (Канон проекта 2.0)

Ниже зафиксированы обязательные правила, устраняющие все дефекты первой итерации:

| Область | Зафиксированное эталонное правило 2.0 |
| :--- | :--- |
| **1. Архитектура виджета (Top Drop-Down Panel)** | Виджет закреплён у **верхней кромки экрана** (Top-Center или Top-Right). В свёрнутом виде виден только аккуратный стеклянный «язычок»-триггер. По клику на кнопку/язычок или по глобальному хоткею (`Win+Ctrl+S` / `Alt+Shift+S`) панель **плавно опускается сверху вниз** на комфортную высоту, а по потере фокуса (`Deactivated`) или `Esc` — плавно уезжает наверх. |
| **2. Абсолютный дефолт (Home Screen First)** | При любом открытии виджета **ВСЕГДА отображается Главный экран с 3 карточками**. Никакого залипания на вложенных экранах. Вложенные экраны (раскрытый список задач, плеер) — это временные слои, которые при закрытии виджета автоматически сбрасываются в исходное состояние `Home`. На каждом экране присутствует явная кнопка «Назад» / закрытия. |
| **3. Взаимодействие окон (Exclusive Focus)** | При открытии полноразмерного окна **Personal Space (Dashboard)** виджет на рабочем столе **гарантированно автоматически закрывается/сворачивается**, исключая визуальный конфликт двух окон. |
| **4. Мгновенный Drag & Drop (Zero Lag)** | Перетаскивание окна работает с **первого же касания мыши без предварительного клика**. Реализуется через мгновенную трансляцию Win32 `WM_NCLBUTTONDOWN (HTCAPTION)` на фоне карточек, не блокируя клики по кнопкам `+`, `Play` и чекбоксам. |
| **5. Настоящий Warm Glassmorphism (No Black Box)** | **Полная ликвидация чёрной подложки окна.** Фон окна строго 100% прозрачный (`Transparent`). Карточки парят прямо над обоями Windows с честным размытием `BackdropBlur(32px)`, тёплым янтарно-медным свечением, световой кромкой `Specular Rim (1px)` и глубокой рассеянной тенью (`Blur 48px`). Внутренние отступы увеличены, края не зажаты. |
| **6. Стабильность плеера DailyReset (Zero Crashes)** | Устранение зависаний и утечек Direct3D: жизненный цикл плеера строго изолирован, медиа-источник освобождается (`Dispose()`) при закрытии, все ошибки кодеков перехватываются через безопасный `try/catch` на уровне `MediaSource`. |
| **7. Честный прогресс и разделение задач** | Задачи дня (*Today's Focus*) после 700-мс анимации уходят в Архив и дают **0%** в счёт месяца. Прогресс месяца ($P = 0.3D + 0.7W$) строится строго на видео-ритуале без перемотки ($30\%$) и недельной цели ($70\%$), привязанной к этапу Большой цели. |

## 3. Ключевые архитектурные дефекты, подлежащие обязательному исправлению

### ДЕФЕКТ 1. Настоящий Warm Glassmorphism вместо «черного гробика» (100% совпадение с референсом image_ff988a.jpg):
1. **Полная ликвидация черного фона окна:**
   - Карточки больше не должны лежать внутри сплошного непрозрачного черного контейнера.
   - Окно виджета (`Window`) обязано иметь строго 100% прозрачный фон (`Background="Transparent"`, `SystemBackdrop = null` с кастомным шейдером или нативный Acrylic/MicaAlt с прозрачностью оконного холста).
   - Никаких черных полей между карточками и вокруг них быть не должно: обои Windows должны мягко просвечивать сквозь зазоры между карточками!
2. **Переработка формулы матового стекла карточек:**
   - Убрать глухую коричневую заливку! Карточка `Today's Focus` должна быть полупрозрачной: `rgba(156, 82, 43, 0.44)` с эффектом аппаратного размытия `BackdropBlur(32px)`.
   - Добавить световую стеклянную кромку (`Specular Rim`): тонкая градиентная обводка `1px` (`LinearGradientBrush(135deg)`: в левом верхнем углу `rgba(255, 210, 170, 0.45)`, плавно уходящая в `rgba(255, 255, 255, 0.08)`).
   - Правая верхняя карточка `Daily Reset` — живое атмосферное превью с теплым золотистым закатным тонированием (как на референсе).
   - Правая нижняя карточка `Quick Hub / This Month` — глубокое темное стекло `rgba(48, 34, 28, 0.62)` с размытием `28px`.
3. **Воздух, скругления и отступы (никаких зажатых краев):**
   - Убрать впритык прижатые границы: внешний `Padding` окна `16-20px`, зазор между карточками `12px`.
   - Углы карточек — плавные и органичные: `CornerRadius="24"`.
   - Под каждой карточкой — мягкая рассеянная тень `DropShadow` (`Offset="0, 16"`, `BlurRadius="40"`, `Color="rgba(0,0,0,0.5)"`), отделяющая стекло от любых светлых и темных обоев рабочего стола.

### ДЕФЕКТ 2. Механика опускания сверху (Top Drop-Down Panel) и хоткей:
1. **Позиционирование у верхней кромки экрана:**
   - Виджет эстетично крепится к верхней границе активного монитора (по центру или в правом верхнем квадранте).
   - **Свернутое состояние (Compact Trigger):** у верхней кромки виден только аккуратный стеклянный язычок-капсула (или компактная полоска карточек).
   - **Раскрытое состояние (Expanded Sheet):** по клику на язычок/кнопку сверху либо по глобальному хоткею (`Win+Ctrl+S` или `Alt+Shift+S`) панель **плавно опускается сверху вниз** на комфортную высоту с пружинной анимацией WinUI Composition (`TranslateY: -100% -> 0`, `280ms`, кривая *Spring Out*).
   - По клику вне панели (`LostFocus / Deactivated`) или по нажатию `Esc` панель плавно уезжает обратно наверх.

### ДЕФЕКТ 3. Мгновенный Drag & Drop без задержки первого клика:
1. **Устранение бага перетаскивания:**
   - Реализовать нативное перетаскивание с ПЕРВОГО касания через вызов Win32 API:
     При событии `PointerPressed` на свободной области карточки мгновенно вызывать:
     ```csharp
     PInvoke.ReleaseCapture();
     PInvoke.SendMessage(hWnd, PInvoke.WM_NCLBUTTONDOWN, (nuint)PInvoke.HTCAPTION, 0);
     ```
   - Кнопки `+`, `Play`, стрелки и чекбоксы должны иметь свой изолированный обработчик (`e.Handled = true`), чтобы клики по ним не триггерили перетаскивание.

### ДЕФЕКТ 4. Устранение тупиковой навигации, сброс в Home и взаимная изоляция окон:
1. **Дефолтный экран — ВСЕГДА Главный экран с 3 карточками:**
   - Запретить сохранение состояния «внутри Today's Focus» как стартового.
   - При любом вызове/разворачивании виджета активным ВСЕГДА открывается Главный экран `Home` (3 карточки).
   - Все вложенные экраны (полный список задач, плеер) открываются как временные скользящие слои, которые при сворачивании виджета автоматически сбрасываются в `Home`.
2. **Явная кнопка «Назад / Свернуть» на каждом экране:**
   - Внутри раскрытого списка задач и внутри плеера ОБЯЗАТЕЛЬНО должна быть видна явная кнопка «← Назад» (или шеврон закрытия) в левом верхнем углу, возвращающая пользователя на экран трёх карточек в 1 клик.
3. **Автосворачивание виджета при открытии Personal Space:**
   - Через шину `WeakReferenceMessenger` при событии открытия полноразмерного окна `Personal Space (DashboardWindow)` посылать команду `CollapseWidgetMessage`.
   - Виджет на рабочем столе обязан немедленно и плавно свернуться наверх, исключая конфликт двух активных окон.

### ДЕФЕКТ 5. Полная ликвидация крашей и зависаний в DailyReset:
1. **Изоляция жизненного цикла MediaPlayerElement:**
   - Запретить инициализацию плеера в главном UI-потоке без перехвата исключений.
   - При переключении экранов, закрытии плеера или сворачивании виджета ВСЕГДА безопасно останавливать воспроизведение и вызывать `MediaPlayer.Source = null;`.
   - Обернуть создание `MediaSource` в защитный блок: если файл поврежден, отсутствует кодек или путь не найден, приложение не должно падать! Вместо краша мгновенно подменять битый файл следующим из очереди `CycleQueue` и показывать мягкий статус `Файл заменен`.
