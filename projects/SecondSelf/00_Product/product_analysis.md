# Product Analysis — Детальный продуктовый анализ Second Self

## 1. Сквозной пользовательский сценарий: от запуска Windows до завершения дня

Чтобы приложение ощущалось естественной частью рабочего стола, его работа выстроена вокруг реального ритма дня специалиста за ПК.

| Этап дня | Действие пользователя / системы | Поведение интерфейса (Widget & Dashboard) |
| :--- | :--- | :--- |
| **01. Старт системы (Утро)** | Включение ПК, вход в Windows | Second Self запускается в фоновом режиме (через автозапуск). Иконка появляется в системном трее. На рабочем столе плавно проявляется **Компактный виджет** в сохранённых координатах монитора. |
| **02. Инициализация дня** | Первый запуск после 04:00 утра | Система фиксирует наступление новых логических суток: выбирает одно случайное видео из локальной Shuffle-очереди и закрепляет его за сегодняшней датой со статусом `Ready`. Невыполненные вчерашние задачи из *Today's Focus* остаются в списке (с мягкой меткой переноса), а выполненные вчера уже находятся в Архиве. |
| **03. Утренняя настройка (2–3 мин)** | Клик по компактному виджету | Панель плавно раскрывается вниз (**Раскрытый виджет**). Пользователь окидывает взглядом 3 карточки: проверяет или добавляет 3 главные задачи в *Today's Focus*, видит карточку *Daily Reset* и текущий *Monthly Progress*. |
| **04. Ежедневный ритуал (Daily Reset)** | Клик по карточке видео (утром или в перерыве) | Открывается встроенный плеер без полосы перемотки. Пользователь смотрит ролик (1–3 минуты), чтобы переключить внимание с суеты на свои приоритеты. После достижения конца ролика появляется кнопка **«Засчитать выполнение»**. По клику на неё дневной ритуал засчитывается (`Daily +1`), а шкала месяца обновляется. |
| **05. Глубокая работа днём** | Работа в 1С, IDE, браузере, переключение столов (`Win+Tab`) | Как только пользователь кликнул в рабочее окно (потеря фокуса виджетом), виджет автоматически свернулся в **Компактный режим**. При запуске приложения во весь экран (Fullscreen) виджет временно скрывается, чтобы не перекрывать интерфейс. |
| **06. Закрытие задач в течение дня** | Клик по выполненной задаче в *Today's Focus* | При клике на задачу открываются 3 SVG-иконки действий (*Выполнить*, *Редактировать*, *Удалить*). Нажатие на *Выполнить* плавно зачёркивает текст, через 700 мс карточка мягко растворяется и переходит в **Архив**. Внизу панели на 5 секунд появляется ненавязчивая плашка **Undo (Отменить)**. |
| **07. Стратегическая сверка (Раз в неделю)** | Переход в **Personal Dashboard** (из трея или кнопки в виджете) | В начале недели пользователь открывает раздел *Goals / Today*, смотрит на свои Большие цели (до 4 активных) и текущие этапы (*Milestones*), после чего формулирует одну **Weekly Goal** на текущую неделю и привязывает её к этапу. |
| **08. Завершение дня / месяца** | Выключение ПК или наступление последнего дня месяца | Все состояния и таймкоды мгновенно сохранены в SQLite, раз в сутки создаётся резервная копия БД. В последний день месяца при открытии виджета или Dashboard активируется экран **Monthly Recap** с итогами месяца и полем для спокойной текстовой рефлексии. |

## 2. Состояния Desktop Widget и логика взаимодействия

Desktop Widget — это **одно окно приложения**, меняющее свою геометрию и композицию через анимации WinUI Composition, а не два разных окна.

### 2.1. Состояние 1: Компактный режим (Compact Mode)
* **Назначение:** фоновое присутствие на рабочем столе (референс `image_7ebeda.jpg`).
* **Состав:**
  * Левая вертикальная карточка **Today's Focus** с кнопкой быстрого добавления (`+`) и списком до 3 текущих задач в виде полупрозрачных капсул.
  * Правая верхняя карточка **Daily Reset** с атмосферным превью сегодняшнего видео и статусом ритуала.
  * Правая нижняя мини-карточка **Progress / Quick Hub** с кратким индикатором прогресса и переходом к полному виду.
* **Поведение:** не перехватывает фокус клавиатуры, свободно перетаскивается за свободную область (с автоматическим сохранением координат), присутствует на всех виртуальных рабочих столах.

### 2.2. Состояние 2: Раскрытый режим (Expanded Mode)
* **Назначение:** активная работа со списком задач дня, запуск видео-ритуала и обзор прогресса месяца (референс `image_7ebe7e.jpg`).
* **Триггер перехода:** клик по кнопке раскрытия или заголовку секции в компактном режиме; обратный переход — клик по нижней стрелке свертывания, клавиша `Esc` или клик вне области виджета (настраиваемая опция *Auto-collapse on focus loss*).
* **Состав (строго 3 вертикальных блока):**
  1. **Блок Today's Focus:** заголовок, подзаголовок *Your daily direction*, кнопка `+`, список задач дня с чекбоксами и меню действий `...`.
  2. **Блок Daily Reset:** заголовок, бейдж состояния (`Ready` / `Paused` / `Completed`), широкоформатное превью видео, название ролика (*Your daily video — A moment to refocus*) и круглая кнопка воспроизведения `Play`.
  3. **Блок This Month:** заголовок, крупный общий процент месяца справа (например, `78%`), горизонтальный прогресс-бар тёплого янтарного цвета и подписи внизу: слева `Daily 26/31`, справа `Weekly 3/4`.

### 2.3. Микровзаимодействия с карточкой задачи
Каждая задача в списке *Today's Focus* проходит через 4 чётких состояния:

1. **Обычное состояние (Default):** круглая иконка статуса слева, текст задачи в одну строку (с многоточием при переполнении), иконка вызова действий справа.
2. **Активное состояние (Selected / Action Bar):** по клику на задачу или кнопку `...` справа плавно раскрываются **три SVG-иконки без текстовых подписей** (при наведении курсора всплывает лаконичный `Tooltip`):
   * `Check` (Выполнить задачу)
   * `Edit` (Переименовать инлайн)
   * `Trash` (Удалить задачу)
3. **Состояние выполнения (Completing — 600–800 мс):**
   * По клику на иконку выполнения кружок слева превращается в отмеченный чекбокс `Done`.
   * Линия зачёркивания (`Strikethrough`) плавно проходит слева направо по тексту задачи, а прозрачность текста снижается до 50%.
   * Спустя 700 мс карточка мягко сжимается по высоте и исчезает из активного списка, перемещаясь в **Архив**.
4. **Окно отмены (Undo Toast — 5 секунд):**
   * После исчезновения задачи (при выполнении или удалении) в нижней части карточки *Today's Focus* на 5 секунд появляется компактная плашка: *«Задача перенесена в архив · [Отменить]»* (или *«Задача удалена · [Отменить]»*).
   * Клик по **«Отменить»** мгновенно возвращает задачу на прежнее место без потери данных.

## 3. Архитектура задач: три уровня обязательств

Ключевое продуктовое решение Second Self — жёсткое разделение оперативной текучки, ежедневной настройки и недельных прорывов.

| Характеристика | 1. Обычная задача (Today's Focus) | 2. Ежедневный ритуал (Daily Ritual) | 3. Недельная цель (Weekly Goal) |
| :--- | :--- | :--- | :--- |
| **Смысл и масштаб** | Оперативные дела на сегодня (*«Закончить задачу по 1С»*, *«Почитать 20 минут»*) | Ежедневная пауза и фокусировка через просмотр 1 видео из личной коллекции | Одно главное достижение недели (*«Завершить модуль авторизации»*) |
| **Количество** | Рекомендуется 3–5 активных задач на день (без жёсткого блока, со скроллом свыше 5) | Строго 1 зачётный просмотр в сутки | Строго 1 главная цель на календарную неделю |
| **Связь с Большими целями** | Нет прямой привязки (чтобы не усложнять быстрое создание за 2 секунды) | Общий ритуал удержания фокуса | Прямая привязка к конкретному Этапу (*Milestone*) одной из Больших целей |
| **Влияние на Monthly Score** | **0%** (защита от инфляции прогресса мелкими бытовыми задачами) | **30%** совокупного результата месяца | **70%** совокупного результата месяца |
| **Куда попадает после закрытия** | В раздел **Archive** (увеличивает счётчики *Сегодня / Эта неделя / Этот месяц*) | В журнал выполненных ритуалов (`Daily +1`) | В историю закрытых недель (`Weekly +1`) и продвигает контекст Этапа |
| **Можно ли редактировать/удалять** | Свободно в любой момент (с поддержкой Undo) | Видео назначается автоматически на весь день | До старта недели — свободно; после старта — изменение фиксируется в истории как отмена/перенос |

### Разница между Архивом и Удалением
* **Архив (Archive):** хранилище побед и реальных результатов. Сюда попадают только выполненные задачи с точной датой и временем закрытия. Они формируют позитивную статистику в разделе *Archive* (*Сегодня: 3 · Эта неделя: 8 · Этот месяц: 26*).
* **Удалённые (Soft Delete / Trash):** задачи, которые потеряли актуальность или были созданы ошибочно. Они не попадают в счётчики выполненных дел и окончательно очищаются из БД через 30 дней.

## 4. Логика Daily Reset (Видео и фиксация просмотра)

Карточка *Daily Reset* превращает просмотр вдохновляющего или настраивающего ролика в осознанный ежедневный ритуал (референс `image_7ebe42.jpg`).

### 4.1. Жизненный цикл видео на день
1. **Формирование пула:** пользователь добавляет в папку/настройки приложения локальные видеофайлы (`.mp4`, `.mkv`, `.webm`, `.mov`).
2. **Алгоритм Shuffle без повторов:** система перемешивает список всех активных видео (алгоритм Фишера — Йейтса) и формирует скрытую очередь воспроизведения (`CycleQueue`). Пока пользователь не посмотрит все видео из очереди по одному разу, повторов не будет. Когда очередь исчерпана, генерируется новый перемешанный цикл (с проверкой, чтобы последнее видео старого цикла не совпало с первым видео нового).
3. **Фиксация за сутками:** при первом запуске приложения после 04:00 утра из очереди берётся следующее видео и жёстко привязывается к текущей дате. Перезапуск программы или перезагрузка Windows в течение дня **не меняют** выбранное видео.

### 4.2. Плеер и состояния просмотра
У карточки и плеера *Daily Reset* четыре последовательных состояния в течение дня:
* **`Ready` (Готово к просмотру):** зелёный бейдж `Ready`, отображается превью и длительность ролика.
* **`In Progress / Paused` (В процессе / На паузе):** если пользователь начал смотреть, но нажал паузу или закрыл плеер, сохраняется позиция `LastPositionMs`. Бейдж меняется на `Paused (00:48 / 01:42)`, позволяя продолжить с того же места в течение текущих суток.
* **`Completed Playback` (Просмотр завершён, ожидает подтверждения):** когда видео доиграло до последней секунды (`01:42 / 01:42`), бейдж сверху меняется на `Completed playback`, а под полной янтарной полосой прогресса плавно появляется крупная акцентная кнопка **«Засчитать выполнение»**.
* **`Counted / Done for Today` (Засчитано сегодня):** после нажатия на кнопку «Засчитать выполнение» система начисляет `+1` к счётчику *Daily Rituals* текущего месяца. Повторно пересмотреть видео в этот же день можно сколько угодно раз, но в зачёт месяца идёт максимум 1 выполнение в сутки.

### 4.3. Правила честного плеера
* **Отсутствие перемотки:** полоса прогресса в плеере является только визуальным индикатором времени (`01:42 / 01:42`) и не реагирует на клики или перетаскивание ползунка (`IsHitTestVisible = false`). Горячие клавиши перемотки вперёд также отключены.
* **Свобода выхода:** доступны кнопка `Play / Pause`, регулировка громкости / `Mute` и закрытие плеера в любой момент. Никакого удержания окна поверх других программ во время паузы.

## 5. Большие цели, Этапы и Personal Dashboard

Если Виджет отвечает за тактику сегодняшнего дня, то **Personal Dashboard** — это стратегический центр управления жизнью и карьерой на горизонте 1–3 лет.

### 5.1. Иерархия целеполагания
Чтобы избежать бюрократии и сложных деревьев проектов, используется строгая трёхуровневая связка:

```text
[Уровень 1: Большая цель (Big Goal)]       --> Например: "Развитие карьеры и архитектуры" (Лимит: до 4 активных целей)
       │
       ▼
[Уровень 2: Этап достижения (Milestone)]   --> Например: "Этап 2 из 4: Создать десктопный продукт Second Self"
       │
       ▼
[Уровень 3: Недельная цель (Weekly Goal)]  --> Например: "Неделя 44: Утвердить ТЗ и архитектуру БД SQLite"
```

* **Карточка Большой цели** содержит: Название, Мотивацию (*«Почему это важно для меня»*), Образ результата (*«Какой конкретный результат должен быть достигнут»*), Горизонт/желаемый срок (например, *2026–2028*), Список этапов (*Milestones*) со статусами (`Completed`, `Current stage · In progress`, `Upcoming`, `Future milestone`).
* **Правило расчёта прогресса Большой цели:** индикатор прогресса Большой цели (например, `2 of 5 milestones`) обновляется **только тогда, когда пользователь явно отмечает завершение Этапа**. Закрытие отдельных недельных задач помогает видеть историю вклада в этот этап, но не двигает шкалу Большой цели автоматически, пока сам этап фактически не завершён.

### 5.2. Пять разделов Personal Dashboard
Навигация основного окна приложения ограничена пятью чистыми экранами без вложенных подменю:
1. **Today (Сегодня):** развёрнутое представление сегодняшнего дня — список *Today's Focus*, активная *Weekly Goal* текущей недели (с указанием, к какому Этапу и Большой цели она привязана) и блок *Daily Reset*.
2. **Goals (Большие цели):** главный стратегический экран (*THE BIG PICTURE*), карточки активных Больших целей (до 4 штук), дорожная карта этапов (*Milestones*) и детальная страница каждой цели.
3. **Progress (Прогресс и итоги):** аналитика текущего месяца (формула 30% / 70%, календарная сетка выполненных ритуалов, таблица 4–5 недель месяца) и коллекция карточек **Monthly Recap** за прошлые месяцы с сохранёнными рефлексиями.
4. **Archive (Архив выполненного):** хронологическая лента всех закрытых задач из *Today's Focus* и выполненных *Weekly Goals* с быстрыми сводками (*Сегодня / Эта неделя / Этот месяц*) и фильтром по периодам.
5. **Settings (Настройки):** управление локальной библиотекой видео (добавление файлов, проверка битых ссылок, сброс очереди), настройка весов прогресса (по умолчанию 30% / 70%), поведение виджета (прозрачность, автосворачивание, монитор), автозапуск Windows и управление резервными копиями SQLite.
