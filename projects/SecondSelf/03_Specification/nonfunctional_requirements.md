# Nonfunctional Requirements — Нефункциональные требования Second Self

**Документ:** `03_Specification/Nonfunctional_Requirements.md`
**Этап:** 4. ТЗ и функциональная спецификация
**Статус:** Версия 1.0 (На согласовании)

## 1. Введение и стандарты качества

Настоящий документ регламентирует стандарты производительности, аппаратной эффективности, надёжности, локального хранения и визуальной плавности для приложения **Second Self 1.0**. Поскольку виджет работает непрерывно на протяжении всего рабочего дня, приложение подчиняется строгим лимитам на потребление системных ресурсов.

## 2. Производительность и потребление аппаратных ресурсов (Resource Efficiency)

| ID | Область | Метрика и критерий качества | Метод верификации | 
| ----- | ----- | ----- | ----- | 
| **NFR-01** | **Холодный старт (Cold Startup)** | Время от запуска исполняемого файла `SecondSelf.exe` до полной отрисовки первого кадра компактного виджета на рабочем столе $\le \mathbf{300\text{ мс}}$ на SSD. | Трассировка через Windows Performance Toolkit (WPT / ETW). | 
| **NFR-02** | **Потребление RAM в простое (Idle RAM)** | В фоновом режиме (виджет на рабочем столе, видео не воспроизводится) рабочий набор памяти (Working Set) $\le \mathbf{65\text{ МБ}}$. | Мониторинг через Windows Task Manager / Process Explorer. | 
| **NFR-03** | **Потребление RAM при воспроизведении видео** | Во время активного декодирования видеопотока 1080p в плеере пиковое потребление RAM $\le \mathbf{140\text{ МБ}}$. | Прогон 10 тестовых видеороликов разной длительности. | 
| **NFR-04** | **Нагрузка на CPU в фоновом режиме** | В состоянии покоя фоновая нагрузка на процессор строго $\mathbf{0.0\% - 0.1\%}$ (полная остановка неактивных таймеров и анимационных циклов). | Замер в течение 10 минут простоя в Performance Monitor. | 
| **NFR-05** | **Аппаратное ускорение видео (GPU Offload)** | Декодирование видео (H.264 / HEVC / VP9) выполняется на специализированных аппаратных блоках GPU (D3D11VA / DXVA 2.0). Нагрузка на CPU во время просмотра $\le \mathbf{3\%}$. | GPU-Z / Task Manager GPU Video Decode Engine. | 
| **NFR-06** | **Плавность рендеринга (Framerate)** | Все анимации изменения геометрии окна, кросс-фейда и зачёркивания задач выполняются с частотой $\ge \mathbf{60\text{ FPS}}$ (на мониторах 120/144 Гц — с нативной частотой обновления без микрофризов). | Счётчик кадровой частоты `DirectComposition / DwmGetCompositionTimingInfo`. | 

## 3. Отклик интерфейса и интерактивность (UI Responsiveness)

| ID | Пользовательское действие | Максимально допустимое время отклика | Поведение системы | 
| ----- | ----- | ----- | ----- | 
| **NFR-07** | Клик раскрытия виджета (`Compact -> Expanded`) | $\le \mathbf{16\text{ мс}}$ до старта анимации | Анимация изменения размеров окна начинается в первом же кадре после клика. | 
| **NFR-08** | Сохранение задачи по нажатию `Enter` | $\le \mathbf{25\text{ мс}}$ | Текст задачи мгновенно валидируется и появляется в UI; асинхронная запись в SQLite выполняется в фоне. | 
| **NFR-09** | Старт воспроизведения видео в плеере | $\le \mathbf{150\text{ мс}}$ | Нулевая пауза перед показом первого кадра из локального кэша превью до инициализации потока. | 
| **NFR-10** | Переключение вкладок в Dashboard | $\le \mathbf{40\text{ мс}}$ | Мгновенный переход без видимых мерцаний и подгрузок (XAML страницы закэшированы в памяти). | 
| **NFR-11** | Перемещение виджета мышью (Drag & Drop) | 0 мс задержки (ровно за курсором) | Выполняется нативно через оконное сообщение `WM_NCLBUTTONDOWN (HTCAPTION)`. | 

## 4. Надёжность, отказоустойчивость и хранение (Reliability & Local-First)

| ID | Требование | Инженерный стандарт реализации | 
| ----- | ----- | ----- | 
| **NFR-12** | **100% Автономность (Zero Cloud Dependency)** | Приложение не совершает сетевых вызовов (исходящий трафик строго равен 0 байт). Функциональность на 100% доступна без подключения к интернету. | 
| **NFR-13** | **Транзакционная целостность SQLite (ACID)** | База данных работает в режиме `WAL` (`journal_mode = WAL`) со строгим контролем внешних ключей (`foreign_keys = ON`). Завершение работы ОС или аварийное отключение питания не приводят к повреждению базы. | 
| **NFR-14** | **Непрерывность сессии (Zero State Loss)** | Текущие координаты виджета, таймкоды видео, активные черновики ввода и открытые вкладки автоматически восстанавливаются в исходном виде после перезагрузки Windows. | 
| **NFR-15** | **Автоматические бэкапы (Point-in-Time Recovery)** | Ежедневное создание атомарного снапшота базы данных через SQLite Backup API без блокировки пользовательского интерфейса. Автоматическая ротация последних 14 копий. | 
| **NFR-16** | **Самовосстановление после сбоя диска** | При обнаружении критического сбоя БД (`database disk image is malformed`) система автоматически разворачивает последний валидный бэкап из `Backups/` с уведомлением пользователя в UI. | 

## 5. Доступность, визуальная гигиена и эргономика (Ergonomics & Accessibility)

| ID | Параметр | Стандарт реализации | 
| ----- | ----- | ----- | 
| **NFR-17** | **Контрастность текста (WCAG Standards)** | Все текстовые элементы основного интерфейса соответствуют стандарту **WCAG 2.1 AA** (контраст к подложке $\ge 4.5:1$), а заголовки и ключевые числовые метрики — стандарту **AAA** ($\ge 7.0:1$). | 
| **NFR-18** | **Табличные цифры (Tabular Numerals)** | Для всех таймкодов плеера (`01:42 / 01:42`), процентов месяца (`78%`) и счётчиков прогресса включён режим `tnum`, предотвращающий горизонтальное дрожание текста при изменении чисел. | 
| **NFR-19** | **Поддержка масштабирования Windows (DPI)** | Корректный рендеринг при масштабах `100%`, `125%`, `150%`, `175%`, `200%` и `250%` без эффекта размытия шрифтов (Per-Monitor DPI V2). | 
| **NFR-20** | **Управление с клавиатуры (Keyboard Navigation)** | Полная доступность навигации без мыши: раскрытие виджета по глобальному шорткату, быстрое добавление задачи (`Alt+Shift+N`), закрытие по `Esc`, воспроизведение/пауза по `Пробелу`. | 

## 6. Безопасность и изоляция данных (Security & Privacy)

| ID | Требование | Описание реализации | 
| ----- | ----- | ----- | 
| **NFR-21** | **Приватность личных рефлексий** | Текстовые записи рефлексий месяца (`MonthlyRecaps`), задачи и цели хранятся исключительно в локальной базе `secondself.db` в пользовательской директории `%LocalAppData%/SecondSelf` и никогда не покидают устройство. | 
| **NFR-22** | **Отсутствие телеметрии** | В коде приложения полностью отсутствуют сторонние трекеры, аналитические SDK и сборщики краш-логов (никаких Google Analytics, AppCenter или Sentry). | 
| **NFR-23** | **Работа без прав администратора (Standard User)** | Приложение устанавливается и функционирует в изолированном пользовательском профиле без требования повышения привилегий UAC (Administrator rights не требуются). |
