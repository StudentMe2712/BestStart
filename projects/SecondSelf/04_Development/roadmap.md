# Roadmap — Дорожная карта проекта Second Self

**Документ:** `04_Development/Roadmap.md`
**Этап:** 5. Декомпозиция разработки
**Статус:** Версия 1.0 (На согласовании)

## 1. Стратегия вывода продукта на рынок и эволюция версий

Разработка **Second Self** разбита на три логических релиза:
1. **MVP 1.0 (Core Focus & Presence):** минимальный самодостаточный десктопный продукт для ежедневного личного использования (виджет, ритуал без перемотки, честный прогресс, цели и локальная БД).
2. **Release 1.1 (Polish & Ergonomics):** кастомизация стеклянных тем, расширенная аналитика архива, глобальные шорткаты и профили настроек.
3. **Version 2.0 (Ecosystem & Insights):** локальные текстовые заметки к этапам, интеграция с локальным аудио-фокусом (Ambient soundscapes) и портативный экспорт отчётов.

## 2. Фазы разработки версии 1.0 (От фундамента до Production)

```text
Фаза 0: Спецификация ────► Фаза 1: Ядро и БД ────► Фаза 2: Виджет и Задачи ────► Фаза 3: Плеер и Ритуал ────► Фаза 4: Dashboard ────► Фаза 5: Тестирование и Релиз
    [Завершено]                [Спринт 1]                [Спринт 2]                  [Спринт 3]              [Спринт 4]             [Спринт 5]
```

### Фаза 0: Продуктовая и техническая спецификация (Завершено)
* [x] Согласование Vision, продуктовых правил (смена дня в 04:00, ISO-8601 недели, 30%/70% прогресс).
* [x] UX/UI-спецификация в стиле Warm Glassmorphism (виджет, плеер, Dashboard, токены).
* [x] Архитектура C# 14 / .NET 10, модель данных SQLite (DDL, триггеры, миграции) и NFR.
* [x] Формирование критериев приёмки BDD (AC-01 .. AC-14).

### Фаза 1: Фундамент приложения и уровень данных (Спринт 1)
* [ ] Каркас решения WinUI 3 (Windows App SDK 1.7) + .NET 10 (Single Project).
* [ ] Настройка DI-контейнера (`Microsoft.Extensions.DependencyInjection`).
* [ ] Инициализация SQLite в режиме WAL, выполнение миграций `001_Initial_Schema.sql`.
* [ ] Реализация репозиториев и сервисов: `TaskService`, `ProgressCalculationEngine`, `BackupService`.
* [ ] Настройка системного трея (`Shell_NotifyIconW`) и автозапуска через реестр Windows.

### Фаза 2: Desktop Widget и управление задачами (Спринт 2)
* [ ] Создание безрамочного окна `WS_POPUP`, `WS_EX_TOOLWINDOW` с прозрачностью.
* [ ] Интеграция с `IVirtualDesktopManager` (отображение на всех столах `Win+Tab`).
* [ ] Верстка компактного режима (3 карточки) с шейдерами размытия `BackdropBlur`.
* [ ] Реализация анимации раскрытия панели вниз через WinUI Composition (`280 мс`).
* [ ] Список *Today's Focus*: инлайн-ввод задачи по `Enter`, трёхкнопочная панель действий.
* [ ] Двухфазная анимация закрытия задачи (зачёркивание 350 мс + схлопывание 350 мс) и тост Undo (5 сек).
* [ ] Детектор полноэкранных игр и медиа (`SHQueryUserNotificationState`).

### Фаза 3: Видеоплеер и ритуал Daily Reset (Спринт 3)
* [ ] Сервис сканирования локальной видеотеки и алгоритм Shuffle Фишера — Йейтса без повторов.
* [ ] Логика фиксации видео за сутками с переключением в `04:00` утра.
* [ ] Встраивание `MediaPlayerElement` с аппаратным GPU-декодированием (D3D11VA).
* [ ] Блокировка полосы перемотки (Seek bar disabled), контролы паузы и громкости.
* [ ] Автосохранение позиции воспроизведения каждые 2 секунды в `DailyRitualLogs`.
* [ ] Появление янтарной кнопки «Засчитать выполнение» по окончании ролика и начисление баллов.
* [ ] Механизм бесшовной замены битых и удалённых файлов.

### Фаза 4: Personal Dashboard и Большие цели (Спринт 4)
* [ ] Верстка стандартного окна приложения 1120×780px и навигационного сайдбара (5 табов).
* [ ] Экран **Today**: связка недели с текущим этапом и задачи дня.
* [ ] Экран **Goals (*THE BIG PICTURE*)**: лимит 4 целей, сегментные шкалы, дорожная карта этапов (*Milestones*).
* [ ] Экран **Progress**: календарная сетка ритуалов, карточки 4/5 недель по ISO-8601, формула 30/70%.
* [ ] Экран **Archive**: счётчики побед (*Сегодня/Неделя/Месяц*) и фильтруемая лента выполненных дел.
* [ ] Экран **Settings**: управление видеотекой, слайдер весов, опции виджета, бэкапы.
* [ ] Модальный оверлей **Monthly Recap**: финализация месяца и сохранение текстовой рефлексии.

### Фаза 5: Стабилизация, профилирование и полировка (Спринт 5)
* [ ] Прогон всех сценариев приёмки `AC-01 .. AC-14`.
* [ ] Профилирование производительности через WPT/PerfView (проверка холодного старта $\le 300\text{ мс}$ и RAM $\le 65\text{ МБ}$).
* [ ] Стресс-тестирование мультимониторности (отключение/подключение дисплеев, смена DPI).
* [ ] Проверка аварийного восстановления БД при резком закрытии процесса.
* [ ] Сборка дистрибутива (Self-Contained MSIX / Portable zip).
