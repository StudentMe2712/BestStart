# Спецификация проекта: DropZone (Dynamic Notch for Files)

## 1. Обзор проекта
**DropZone** — это легковесная десктопная утилита для Windows на базе C# (.NET 8) и WPF, выполненная в стиле «Dynamic Island / Notch». Она крепится к верхнему краю экрана поверх всех окон и служит временным интерактивным «карманом» для быстрой передачи файлов между приложениями (например, с Рабочего стола в браузер, мессенджер или видеоредактор), избавляя от необходимости жонглировать окнами и `Alt+Tab`.

## 2. Архитектурный Стек
- **Платформа:** .NET 8.0 (Windows Desktop)
- **UI-фреймворк:** WPF (Windows Presentation Foundation) с разметкой XAML
- **Интеграция с ОС:** Нативные механизмы WPF Drag-and-Drop (`DataFormats.FileDrop`, `DragDrop.DoDragDrop`), безрамочное стекломорфное окно (`WindowStyle="None"`, `AllowsTransparency="True"`).

4. Требования к UI/UX (Внешний вид и Поведение)
Позиционирование: Окно не имеет стандартных рамок (WindowStyle="None"), поддерживает прозрачность (AllowsTransparency="True"), закреплено поверх остальных (Topmost="True"), прилипает к самому верху экрана (Top="0") и автоматически центрируется по горизонтали.

Дизайн: Темный стекломорфный фон с закругленными углами снизу (CornerRadius="0,0,20,20"), мягкая падающая тень (DropShadowEffect).

Состояния:

Когда карман пуст — отображается текст-заглушка: "Перетащи файлы сюда...".

При добавлении файлов заглушка скрывается, а файлы отображаются в виде горизонтального скроллящегося списка стильных чипов (плашек) с именами файлов.
