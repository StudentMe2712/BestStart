# OmniLeadSniper (TgOrderSniper) — Claude Code Rules

Project-specific instructions for Claude Code. This file overrides / extends the
baseline philosophy in the root `CLAUDE.md`.

**OmniLeadSniper** — высокопроизводительный асинхронный сервис для мгновенного перехвата,
скоринга и доставки коммерческих IT-заказов и лидов из Telegram-каналов, глобального поиска Telegram
и веб-бирж (Хабр Фриланс, Kwork) в закрытую группу команды.

---

## 🛠 Технологический стек и архитектура
- **Язык & Среда**: Python 3.10+, асинхронный event loop (`asyncio`).
- **Сбор данных**: Telethon MTProto (Userbot-клиент), HTTPX + BeautifulSoup (Хабр Фриланс), Playwright Chromium (Kwork).
- **Фильтрация и скоринг**:
  - `Privacy Gatekeeper`: запрет исходящих сообщений (`out`), личных переписок (`is_private`), сообщений длиннее 1500 символов и маркеров исходного кода.
  - Коммерческий regex pre-filter: отсечение нерелевантного шума.
  - Groq LPU AI Classifier: структурированный скоринг лидов (`is_lead`, `category`, `budget`, `summary`).
  - **Anti-Hallucination Guard**: бюджет извлекается ТОЛЬКО при явном наличии суммы и валюты в тексте; иначе строго `""` / `null`.
- **Хранилище & Дедупликация**:
  - SQLite (`data/sniper.db`, async SQLAlchemy + aiosqlite).
  - Композитная дедупликация: `(source, external_id)` + SHA-256 `content_hash` + LRU-кэш в памяти.
- **Доставка**: Асинхронный Telegram Bot API диспетчер через HTTPX (`[🔗 Открыть задачу]` / `[🔍 Открыть пост]`).
- **Точки запуска**:
  - `python run.py` — единый запуск с pre-flight проверкой и авто-fallback сессий.
  - `start.bat` — запуск в 1 клик на Windows (UTF-8, автодетект Python).

## 📊 Session Context Tracking (MANDATORY IN EVERY RESPONSE)

В конце каждого своего ответа ОБЯЗАТЕЛЬНО выводи визуальный прогресс-бар заполнения контекста сессии в формате:
`[Контекст: ████░░░░░░░░░░░░░░░░] 20% (~40k / 200k токенов)`

Правила расчёта и отображения:
- Номинальный лимит контекста сессии: 200k токенов (200,000 токенов).
- Длина прогресс-бара: 20 блоков (`█` — 5% на блок, `░` — пусто).
- Формат: `[Контекст: ████░░░░░░░░░░░░░░░░] XX% (~YYk / 200k токенов)`.
- Если процент превышает 75%, выводи предупреждение:
  `⚠️ Рекомендуется начать новый чат.`
