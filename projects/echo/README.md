# Echo — личный Telegram-компаньон

Echo сам пишет тебе первым: короткие умные сообщения — вопрос, мысль, брейншторм,
мягкое напоминание встать и подышать. Не по тупому расписанию, а в осмысленный момент:
с учётом времени суток, дневного лимита, пауз и того, на что ты реагируешь. Умеет молчать.
Один пользователь, только Telegram, локальный запуск.

> One-liner: личный Telegram-компаньон, который сам пишет короткие умные сообщения,
> задаёт вопросы, провоцирует на мысль, вдохновляет и мягко напоминает о себе — без спама.

## Как это работает

```
APScheduler (тик раз в TICK_MINUTES)
        │  окно дня + лимит + пауза + вероятность + штраф за игнор
        ▼
  выбор роли (вес × смещение окна, без повтора подряд)
        ▼
  генератор: Groq → OpenRouter → шаблоны   (фильтр качества на каждом кандидате)
        ▼
  Telegram (aiogram)  →  лог в SQLite
        ▲
  реакция/ответ пользователя → подстройка весов ролей
```

- **Echo — один характер, а не набор ботов**: близкий друг, который иногда пишет. Четыре
  интонации: **Друг** (основная — интерес к твоей жизни), **Тренер** (короткие пинки про тело),
  **Наставник** (вопросы про реальные дела), **Челленджер** (редкий неудобный вопрос — только
  по контексту, никогда по расписанию).
- **Реакция важнее мудрости**: когда ты что-то рассказываешь, Echo отвечает интересом к тебе
  («о, круто, какие планы?»), а не философией.
- **Кнопки 👍 / 👎 / 🤔** под каждым сообщением — основной сигнал обучения: что заходит, что нет.
- **Без спама**: тихие часы, лимит в день, минимальный интервал, вероятностная модель,
  снижение частоты после игнорирования.
- **Фильтр качества** перед каждой отправкой: длина (коротко!), банальность (штампы, афоризмы,
  мотивационный мусор), токсичность, повтор недавних тем.
- **Память/предпочтения**: интонации, на которые ты отвечаешь или ставишь 👍, становятся чаще; 👎 — реже.
- **Отказоустойчивость**: если LLM недоступны — берётся курируемый банк сообщений (бот живой даже офлайн).

## Запуск

1. Скопируй конфиг и заполни значения:
   ```bash
   cp .env.example .env       # вписать TELEGRAM_BOT_TOKEN, OWNER_USER_ID, ключи Groq/OpenRouter
   ```
   - Токен бота — у **@BotFather**. Свой numeric id — у **@userinfobot**.
   - Ключи можно оставить пустыми — тогда Echo работает на шаблонах.
2. Подними контейнер:
   ```bash
   docker compose up --build      # остановить: docker compose down
   ```
3. Напиши боту `/start` в Telegram.

`.env` и база `data/echo.db` — в `.gitignore`, в репозиторий не попадают.

## Команды

| Команда | Что делает |
|---|---|
| `/now [роль]` | написать прямо сейчас (для теста; роль опционально) |
| `/mode` | показать роли и их веса |
| `/mode <роль>` | хочу больше таких сообщений |
| `/mode <роль> on\|off` | включить/выключить роль |
| `/more` / `/less` | чаще / реже |
| `/quiet [часы]` | помолчи N часов (по умолчанию 4) |
| `/pause` / `/resume` | выключить / включить |
| `/stats` | статистика |
| `/help` | список команд |

Роли (ключи для команд): `friend, coach, mentor, challenger` (challenger — только реактивно/через `/now`).

## Настройка (`.env`)

`MAX_PER_DAY`, `MIN_GAP_MINUTES`, `QUIET_START`/`QUIET_END`, `TICK_MINUTES`,
`ENABLED_ROLES`, `TIMEZONE`, модели `GROQ_MODEL` / `OPENROUTER_MODEL`. Подробности — в `.env.example`.

## Тесты

В контейнере (без установки на хост):
```bash
docker compose run --rm app sh -c "pip install -r requirements-dev.txt && python -m pytest"
```
Или одноразовый venv:
```bash
py -3.12 -m venv .venv && .venv/Scripts/python -m pip install -r requirements-dev.txt
$env:PYTHONPATH="$PWD"; .venv/Scripts/python -m pytest tests -q
```
