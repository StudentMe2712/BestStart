# SelectCast — инструкция

**Выделил — увидел конвертацию.** Глобальная утилита: выделяете текст в любом приложении,
жмёте горячую клавишу — и видите конвертацию валют / времени / единиц / цвета. Работает офлайн
(кроме курсов валют), живёт в системном трее.

## Что распознаётся
- **Валюта**: `$129`, `129 USD`, `1 299,50 ₽`, `€1.5k` → суммы в KZT / RUB / USD / EUR + дата курса.
- **Время**: `3 PM EST`, `20:00 GMT+3` → Астана / Москва / UTC.
- **Единицы**: `72 °F`, `5 ft 9`, `10км` → метрические/имперские.
- **Цвет**: `#3A7BD5`, `rgb(58,123,213)` → HEX / RGB / HSL + образец.

---

## Запуск готового билда (самый простой путь)
1. Возьмите `dist\SelectCast.exe` (см. «Сборка»). Это один файл, **.NET ставить не нужно**.
2. Запустите его двойным кликом. Появится значок в трее, окно скрыто.
3. При первом запуске Windows SmartScreen / Smart App Control может предупредить о неподписанном
   приложении: **«Подробнее» → «Выполнить в любом случае»** (билд не подписан сертификатом).

## Использование
- Выделите текст в любом приложении и нажмите **Ctrl + Alt + C** (по умолчанию).
- Появится окно с конвертацией. **Enter** — пересчитать введённое вручную, **Esc** — скрыть.
- Двойной клик по значку в трее или меню **«Открыть»** — ввести текст вручную.

## Настройки (смена горячей клавиши)
Трей → **«Настройки»** → кликните поле «Горячая клавиша» и нажмите нужную комбинацию
(минимум один модификатор + клавиша) → **«Сохранить»**. Применяется сразу. Если комбинация
занята другим приложением — будет показана ошибка, выберите другую.

## Автозапуск
Включён по умолчанию (модель «трей + автозапуск»). Переключается в меню трея → **«Автозапуск»**
(пишет/удаляет ключ в `HKCU\…\Run`, без прав администратора).

## Выход
Трей → **«Выход»**. Закрытие окна (×/Alt+F4) только прячет приложение в трей — оно продолжает
ловить горячую клавишу.

## Курсы валют
- Источники по приоритету: **НБК РК → ЦБ РФ → fawazahmed0** (СНГ в первую очередь, иначе зарубежный).
- Обновление не чаще раза в сутки; последний успешный ответ кешируется локально.
- Офлайн — берётся кэш; если все источники недоступны, рядом с датой будет «(возможно устарел)».
- В сеть уходит **только запрос курсов** — ничего из выделенного текста никогда не передаётся.

## Где лежат данные
`%AppData%\SelectCast\` — `settings.json` (хоткей, автозапуск) и `rates.json` (кэш курсов).

## Сборка из исходников
Нужен **.NET 9 SDK**.

```powershell
# из папки проекта
dotnet build SelectCast.sln -c Release     # сборка
dotnet test  SelectCast.sln                # тесты

# self-contained single-file билд → dist\SelectCast.exe (один файл, без установки .NET)
./publish.ps1
```

## Троблшутинг
- **«Не удалось зарегистрировать хоткей …»** — комбинация занята другим приложением.
  Смените её в «Настройки».
- **«SelectCast уже запущен»** — приложение допускает один экземпляр (значок уже в трее).
- **SmartScreen / антивирус ругается на .exe** — билд не подписан; запустите «в любом случае»
  или соберите сами из исходников.
